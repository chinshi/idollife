## 0. 结论先行

1. **2.5 头身是"可爱但不幼稚"的甜点**。2 头身像吉祥物（失去"人"），3 头身偏儿童（恋爱/成长线会别扭）。2.5 头身 + 五头以下的脸部公式，既能承载 6 个表情，也撑得住换装。
2. **可爱不靠"多"，靠"圆"**。v2 的可爱来源排序是：圆轮廓 > 大眼距 > 腮红 > 发梢跳色 > 饰品。颜色再艳，轮廓带一个尖角就崩。
3. **高饱和可以，但不能靠明度分主体**。萌系整体压在高明度（L 70–95），和办公室浅色 UI 底（L 94）几乎同值——必须用**白色外描边 + 深灰紫内线 + 柔和落地投影**把角色"抠"出来。这是 v1 整套逻辑被推翻的地方。
4. **推し色由发色装备承载**：发梢撞色、渐变直接画进发色贴图（如"亮粉发梢的热可可"就是一件发色装备），不再设独立发梢槽。地偶的"担当色"文化保留，槽位让位给装备表的四槽结构。
5. **全身不必涨预算**：Q 版全身 1 页 2048 就够（16MB），比 v1 的半身 20MB 还省。

## 2. 色彩板（中高饱和 · 高明度）

| 角色 | 用途 | 色号 | L | S |
|---|---|---|---|---|
| 主色 | 服装主体 | `#F58CA6` 珊瑚粉 | 75 | 高 |
| 辅色 | 服装次级 / 白 T / 袜 | `#FFF6EA` 奶油白 | 96 | 低 |
| 强调色 | 饰品、发梢、舞台款 | `#6FD6C0` 薄荷青 ＋ `#FFCE5C` 亮黄 | 80 / 82 | 高 |
| 皮肤 | 脸与四肢 | `#FFE0CE` 蜜桃 | 91 | 中 |
| 发色（默认） | 头发本体 | `#8A5A4B` 热可可 | 45 | 中 |
| 发梢撞色 | 发色装备自带的挑染/渐变（非独立槽） | `#FF7FA8` 亮粉（默认发色的撞色） | 72 | 高 |
| 背景 | 办公室 UI 浅底 | `#F2EFE9` | 94 | 极低 |
| 描边 | 内线统一 | `#4A3F4D` 深灰紫 | 30 | 低 |

**硬规则**

1. **同屏高饱和色块 ≤ 2 处**。角色本体最多允许"珊瑚粉 + 一个强调色"同时高饱和，第三处必须降到中饱和。
2. **皮肤必须比服装亮**（L 91 > 服装 L 75）。Q 版的"可爱"有一半来自"脸是亮的"。
3. **发色只能落在 L 35–60**。Q 版头发面积占比大（约 30% 画面），发色过亮会吃掉脸；过暗会在浅底上变成黑块。
4. **发梢撞色是唯一允许高饱和的小面积**（占画面 ≤ 4%），画在发色装备贴图里，承担识别而不是氛围。
5. 状态不能只靠颜色：体力低必须配动作（低头、眨眼变慢、呆毛塌下来），不能只调灰。

## 3. 明度阶梯与"主体怎么从背景里出来"

### 3.1 阶梯（萌系：暗部不下沉）

| 层级 | L 区间 | 落点 |
|---|---|---|
| 高光 | 94–100 | 眼瞳高光、发顶弧、鞋面 |
| 亮面 | 82–94 | 脸部、衣服受光面 |
| 中间调 | 70–82 | 服装固有色、发中间调 |
| 暗部 | **55–70** | 颈下、发内层、裙褶、裤袜 |
| 描边 | 28–38 | 内线 |
| 背景 | 90–96 | 办公室浅底 |

**关键差异**：v1 的暗部压到 22–42，v2 的暗部**不低于 55**。Q 版一旦把暗部压深，画面立刻"脏"，可爱感消失。这是萌系与写实的最大分野。

### 3.2 主体分离靠描边，不靠明度

主体亮面 L 82–94 vs 背景 L 94 → 只差 0~12 点，远不到 2 档。**明度分离在这套风格里失效**，替代方案固定为三层：

| 层 | 规格 | 作用 |
|---|---|---|
| 内线 | `#4A3F4D`，2px（480 宽显示下量） | 结构边界，统一画面 |
| 外光 | `#FFFFFF`，3px，80% 不透明 | 把角色从浅底上"抠"出来；暗底场景换 `#2A2530` |
| 落地投影 | 椭圆，宽 = 角色宽 ×0.7，不透明度 10%，模糊 8px | 给"站"这个动作一个物理落点 |

**验证方法**：把成品贴到 `#F2EFE9` 底色上看 10% 缩略图——如果她的轮廓是靠"白边"而不是靠颜色被认出来的，就算过。若轮廓糊掉，先加粗外光，不要加深内部。

> 这也是为什么"高饱和"能和"摸鱼不显眼"共存：真正让它在办公软件里跳出来的不是颜色，是轮廓的锐利度和运动。白边 + 圆角 + 慢动作，观感接近"贴纸"，反而比暗色写实更不像"正在玩游戏"。

## 4. 角色设定（2.5 头身 Q 版，可直接照着画）

### 4.1 一句话

> 一个头发有点不听话、站在小剧场门口等开场的大头女孩。

### 4.2 比例与五官公式（Q 版必须给公式，不能"看着调"）

| 项 | 规格 | 说明 |
|---|---|---|
| 头身比 | **2.5 头身**，头高 = 全高 40% | 窗口内 360px 高 → 头高 144px；人物页 720px → 头高 288px |
| 头宽:头高 | 1 : 1.05 | 接近圆，略高；正圆会显得像吉祥物 |
| 眼宽 | 头宽 × **0.30** | Q 版眼睛占比是可爱度第一变量 |
| 双眼间距 | 眼宽 × **0.8** | 眼距拉开 = 幼态；紧贴 = 精明 |
| 瞳孔中心位置 | 头顶往下 **58%** | 下移 = 幼态；Q 版不要在头高中线 |
| 眼型 | 圆眼，上眼睑弧度大，**外眼角不上挑也不下垂**（水平） | v1 的下垂 3° 在 Q 版会被读成"萌系下垂眼"，语义反转 |
| 眉 | 短弧，长度 = 眼宽 × 0.7，距眼 6px | 眉不压眼，压了就"愁" |
| 鼻 | **不画鼻梁**，鼻位一个 2px 短弧阴影 | Q 版惯例 |
| 嘴 | 宽 = 眼宽 × 0.55，位于头顶往下 82%；默认形状为短弧 | 张嘴时是"ω"形 |
| 腮红 | 两道斜椭圆，中心在眼下 8px，宽 = 眼宽 × 0.7 | **可爱度开关，不可省** |
| 躯干 | 高 = 头高 × 0.55（含颈），无腰线，直筒 | Q 版不画腰 |
| 腿 | 长 = 全高 × 0.30（含鞋）；大腿:小腿 ≈ 1:1 | 腿短 = 幼；腿长 = 成熟 |
| 手臂 | 上臂 + 前臂各 = 头高 × 0.22；**小圆手**，直径 = 头宽 × 0.18，不画手指 | 手指在 144px 头高下只有 4px，画了就是噪点 |
| 脚 | 鞋长 = 头宽 × 0.45 | |
| 站姿 | 脚尖内八 8°，重心偏右 2px，双肩不等高 1px | 内八 + 轻微不对称 = 可爱 + 活人感 |

### 4.3 记忆点（Q 版剪影层）

| # | 记忆点 | 层级 | 10% 缩略可读 | 优先级 |
|---|---|---|---|---|
| 1 | **折两折的"问号形"呆毛**，长 = 0.5 头高，向右外翻 | 剪影 | ✅ 第一识别 | P0 |
| 2 | **默认发色的发梢撞色**（热可可 + 亮粉，12% 高度渐层，由发色装备承载） | 色彩识别 | ❌（100% 尺寸可读） | P0 |
| 3 | 不对称：发型 B 双马尾右高左低（差 0.08 头高） | 剪影 | ✅ | P0 |

**为什么是这三个**：Q 版能承载的"设定符号"极少（脸太小、身体太短），记忆必须压缩进剪影和一条颜色。呆毛负责"一眼认出"，发梢撞色负责"这是**我的**角色"——后者正好接上地偶的"担当色"文化，也让发色装备有了情感锚点。

**验证方法**：整图涂黑缩到 10%，应能认出"一个大头、右上一根折两折的呆毛"。若呆毛和头发糊成一块，把呆毛的**间隙**拉开（呆毛根部与头顶留 3px 空隙），不要把它加粗。

### 4.4 表情（6 个 P0 + 2 个 P1，Q 版表情要更夸张）

| 表情 | 参数要点 | 用在哪 |
|---|---|---|
| 默认 | 眼圆睁、短弧嘴、腮红 40% | 常驻 |
| 微困 | 上眼睑压 25%、嘴变平、**呆毛塌 15°** | 体力低 / 深夜 |
| 抿嘴笑 | 眼下弧上抬、嘴角 +2°、腮红 80%、眼睛眯成 ⌒ | 被夸 / 事件成功 |
| 惊讶 | 瞳孔缩 12%、嘴变 "o"、呆毛弹起 20% | 事件触发 |
| 不悦 | 眉下压、嘴变 "へ"、腮红 20% | 冲突事件 |
| 紧张 | 眉内端上抬、瞳孔微颤 | 试镜 / 上台前 |
| （P1）喘 | 张嘴、肩抬、呼吸振幅 ×1.8 | 排练后 |
| （P1）哭 | 下眼睑积水高光、嘴抖、呆毛全塌 | 结局 |

> Q 版的表情分辨率比写实高得多——因为脸占了 40% 画面。**这是 Q 版最该吃干榨净的优势**：同样 6 个表情，在 Q 版里的情绪传递效率约是 6.5 头身的 2 倍。所以表情数量可以少，但每张必须夸张到位。

### 4.5 不允许出现的（角色层禁忌）

- ❌ 任何尖角：下颌、发梢、鞋头、衣角一律圆角（Q 版最容易被"写实笔触"破坏的就是圆）
- ❌ 纯黑描边（在浅底上过重，会变成"贴纸黑边"而不是"画"）
- ❌ 深暗部（L < 50）——画面立刻脏
- ❌ 上挑大眼 + 成排睫毛（Q 版这两样会变成"廉价手游脸"）
- ❌ 手指分节、鼻梁、锁骨、肌肉线（144px 头高下全是噪点）
- ❌ 依赖设定的装饰（纹身、伤疤、职业道具）——玩家换模板就穿帮
- ❌ 真实团体 / 品牌 / 应援色组合

## 5. 三种"可爱"的质地（都高饱和，区别在软硬）

| 方向 | 一句话 | 视觉特征 | 制作成本 | 结论 |
|---|---|---|---|---|
| **C1 奶油糖果（推荐）** | 圆、软、无锐角，像一颗糖 | 中高饱和 + 高明度，深灰紫内线 + 白外光，暗部不低于 55 | 基准 | 与"地偶可爱"最贴，且 Live2D 分层最省（平涂两档） |
| C2 果冻高光（韩系） | 有透明感，眼睛像玻璃 | 每部位多一层高光 + 环境色反射，眼瞳 3 层 | **+40%**（每片 ArtMesh 多 1–2 层，纹理涨一页） | 更"闪"，但和"日常/略疲惫"的基调冲突 |
| C3 波普贴纸 | 粗描边、纯平色、强对比 | 内线 4px、无阴影、高饱和撞色 | **−20%**（最省） | 便宜、辨识度最高，但"可爱"偏硬，长期看不耐看 |

**推荐 C1**。若后面觉得"不够抓眼"，正确做法是**先给发梢与饰品加饱和**（局部提亮），而不是整体提饱和——整体提饱和会让 6 个表情全部糊在一起。

## 6. 表现约定

### 6.1 角色与 UI 同框

- 角色与面板之间留 8px 空白 + 1px `#00000014` 分隔线（贴纸感来自"没有边界"）。
- 外光（白 3px）只在浅色底启用；深色舞台场景换成暗外光 `#2A2530`，否则会出现一圈"发光"，很出戏。
- 舞台事件允许整体压暗背景：背景压到 L 35 + 一层薄荷青，但**角色本体饱和度不动**（靠背景变暗来突出，而不是角色变艳）。

### 6.2 尺寸与"摸鱼"约束（项目独有）

[01](01-产品定位与目标用户.md) §2.2 写明：办公场景里"大幅可识别的绘画"会让玩家被辨认出在摸鱼。v2 走高饱和可爱风，这条冲突更尖锐，所以对策从"降饱和"换成"降冲击"：

1. **尺寸 260×360 封顶**（约屏幕 12%），不做全屏立绘；
2. **降"静"不降"色"**：待机 8 秒循环、无粒子、无高频闪烁、无音效。可爱靠形态，不靠动效轰炸；
3. **剪影版**：同网格导出全黑剪影贴图，一键切 40px 缩略；
4. **灰度模式（v2 新增）**：一键转灰，保留双描边。高明度萌系在灰阶里依然可读——因为可爱靠轮廓与比例，不靠颜色。这是 v2 相对 v1 多出来的一个退路，也最适合办公场景。

> 仍需产品确认：这一步实质修订了 01 的"不做美术/立绘"反需求，应在 [16 决策记录](16-决策记录.md) 留一条。

### 6.3 档位

| 档 | 形态 | 工作量 | 技术依赖 |
|---|---|---|---|
| **L0** | 1 张全身 Q 版静态立绘 + 6 表情差分 + CSS 呼吸/轻晃 | 2–3 人日 | 无（`<img>` 切换） |

## 7. 禁忌清单

1. 不模仿在世画师个人风格；不生成受版权保护的角色。
2. 不用渐变、体积光、镜头光斑、粒子装饰。
3. 不用纯黑描边、不用深暗部（L<50）。
4. 不做尖角（下颌/发梢/鞋头/衣角）。
5. 不做上挑大眼、成排睫毛、手指分节。
6. 不做"卖萌"姿态（歪头 + 举拳 + 星星眼）——与"没野心、走一步看一步"的主角冲突，可爱要靠形态不靠姿势。
7. 不在同一张图混用两种描边策略（内线 2px 必须统一，外光只在交付时整体加）。
