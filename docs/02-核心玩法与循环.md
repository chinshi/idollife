# 02 · 核心玩法与循环

> 状态：🟠 填充中 ｜ 负责人：陈曦 ｜ 更新：2026-10-29
> 上游：01 定位 ｜ 关联：04 数值 · 08 摸鱼场景 · 12 时间系统 · 18 联机

## 本文回答什么

- 玩家打开页面后，**每一轮**具体在做什么？
- 一轮多长？几次点击？什么时候给他「变强了」的反馈？
- 时间怎么推进？玩家需要多频繁地介入？

## 0. 需求里的循环原型

原始文档给出的玩家目标：

> 玩法 → 提升偶像养成数值 → 数值转化为收入 → 收入用于提升数值 → 获得成就感与养成感

本文要把它写成**可执行的一轮流程**。

## 1. 核心循环（文字版流程图）

```Plaintext
[选择行动] → [消耗时间/体力] → [结算属性与资源] → [文字反馈] → [收入/名气变化] → [解锁新行动] → 回到选择
```

【日常养成环节】

[选择行动] → [消耗时间/体力] → [结算属性与资源] → [文字反馈] → [属性/货币变化] → 回到选择

【演出收益环节】

[选择行动] → [配置演出细节] → [结算收益] → [文字反馈] → [获得高额收入]

【核心流程】

[选择行动] → [消耗资源] → [结算属性与资源] → [文字反馈] → 回到选择

【资源循环】

[进行训练和准备活动（消耗时间+金钱）] → [增加属性/下降状态] → [参与活动和事件（利用属性和时间）] → [获得货币/下降状态] → [使用道具和触发事件（货币和时间）] → [恢复状态/减少货币]

【联机环节（中期核心）】

[每周配置企划] → [截止锁定] → [到点服务器统一演算] → [文字战报 + 排名 + 奖励] → 回到日常

> 联机只加一层「周结算」，不侵入日常循环。详见 [18 联机与异步结算](18-联机与异步结算.md)。

## 2. 单次会话（1–5 分钟）

|步骤|玩家动作|界面反馈|耗时|
|---|---|---|---|
|1|打开页面，看到当前状态|反馈状态值+属性值+计划表+|5 秒|
|2|选择一项行动|行动内容+行动的资源消耗+行动预估收益+耗时配置+开始按钮|15 秒|
|3|看到结算与文本|属性变化+状态变化+货币变化+其他收益+行动决策|20 秒|
|4|决定继续还是离开|行动安排提醒+预估结果|—|

> 设计红线：**任何一次「离开」都不能让玩家觉得亏了。** 摸鱼场景下，玩家随时可能被老板叫走。

## 3. 时间与节奏模型

|方案|说明|优点|代价|
|---|---|---|---|
|A. 真实时间驱动|行动消耗现实分钟数，靠等待推进|最贴合「慢节奏」|玩家可能觉得无事可做|
|B. 游戏内天数|玩家主动「结束今天」，直接推进|可控、爽快|「慢」的感觉弱化|
|C. 混合|后台按真实时间累积，前台用游戏内天结算|兼顾两者|规则复杂、易出 bug|

【已定】方案 D（新增）：**排程驱动**。行动消耗游戏内时间，玩家预排后自动流逝；现实时间不参与推进。

> 每个行动消耗多少游戏时间随阶段变化，见 §5.1。联机判定另用服务器时间，见 [18](18-联机与异步结算.md)。

## 4. 成长阶段

|阶段|进入条件|可用玩法|玩家目标|
|---|---|---|---|
|**练习生**|初始（生存期，真实 10–30 分钟）|训练 / 属性培养 / 打工|活下去，攒钱，属性达到出道线|
|**出道期**|属性综合达标，报名出道演出|出道演出、组合组建、媒体|通过出道演出，找到定位|
|**固定成员**|出道演出通过，组合稳定|固定演出、排练、通告|稳定产出，积累粉丝|
|**人气成员**|粉丝数达标|外务、商务、拼盘、组团演出|扩大影响，冲更高收益|

> 【已定】共 4 个阶段。已**砍掉「地上环节」**（转入主流），全程围绕地下偶像展开——周期变短、主题更集中。
> 进入条件：出道期为「出道演出」，其余为数值门槛，具体数值后定。
> 每阶段对应一次「玩法解锁」，而不是只涨数值。

## 5. 时间推进方式（2026-10-29：删去番茄钟）

> ⚠️ 番茄钟整体废弃，见 [16 D-009](16-决策记录.md) 与 [12](12-番茄钟与时间系统.md)。原因：番茄钟要求「人在场专注」，而本作机制是「排程 → 自动流逝 → 无排程则静止」，两者互斥。

```
[玩家排程] → [自动行动 + 时间流逝] → [遇事件 / 排程结束 / 手动停] → 静止，等决策
```

### 5.1 各阶段的行动跨度

| 节奏段 | 对应阶段 | 一个行动推进 | 玩家介入频率 |
| --- | --- | --- | --- |
| 生存期 | 练习生 | 1 游戏日 | 每天，决策密 |
| 过渡期 | 出道期 | 数日 – 1 周 | 每 2–3 天 |
| 养成期 | 固定成员 → 人气成员 | 1 – 4 周 | 每次事件 |

> 节奏段 ↔ 成长阶段：生存期 = 练习生；过渡期 = 出道期；养成期 = 固定成员 + 人气成员。

### 5.1.1 周结构（2026-10-29）

| 时段 | 行动数 | 内容 |
| --- | --- | --- |
| 周中（周一–周五） | 10 个 | 训练、打工、休息、通告 |
| 周末（周六–周日） | 4 个 | 日常演出（自动）+ 可报名**大演出**（自选） |

- 1 行动 = 流逝 **10 分钟**游戏时间
- 1 游戏周 = 14 行动 = 140 分钟流逝
- 2 年 = 104 周 = 1456 行动 ≈ **243 小时**流逝
- 每天平均 2 个行动；玩家可按周 / 按月排程，不必逐日操作

> 大演出：每 2 个游戏周开放一次，**自选**参加，消耗更高、收益 1.1–1.25 倍，不打也不惩罚。见 [18](18-联机与异步结算.md)。

### 5.2 两条保留的约束

1. **不把玩家绑在「等一天」的节奏上**：时间由排程推进，不是现实日历。
2. **产出恒定，只变颗粒度**：单位时间产出前后一致，成长来自机会质量，不来自效率膨胀。见 [04 §5.2](04-数值与经济.md)。

## 6. 失败与惩罚

| 问题 | 结论 |
| --- | --- |
| 是否允许破产 / 掉粉 / 糊掉 | 【已定】允许。初期负债到一定阈值 → 被迫归家 → 触发**结束结局** |
| 失败后是重开还是可恢复 | 【已定】只可重新开始；另允许 debuff 期，或回溯到 N 天前（回溯不触发 debuff） |
| 惩罚形式 | 收益下降 / 属性下降由玩家自行选择；多次失败**叠加 debuff** |
| 摸鱼场景能否承受 | 【待填】被老板叫走导致的失败，算不算玩家的错？ |

### 6.1 结局模型（2026-10-29 补充）

**任意阶段都可能触发结局**，不只在人气成员。人气成员是最终阶段，但不是唯一终点。

| 触发点 | 典型结局 |
| --- | --- |
| 练习生 | 负债归家、放弃 |
| 出道期 | 出道失败、错过窗口 |
| 固定成员 | 组合解散、被替换 |
| 人气成员 | 生涯结局（好 / 普通） |

由此周期是「**上限 + 提前结束**」：跑到上限必出结局，中途也可能提前结束。

> **周目上限：游戏内 2 年**（第 2 年尾声触发「留圈抉择」）。 现实 7–14 天是期望值，**不作为控制项**。
>
> **时间流逝机制**：玩家排程 → 自动行动并流逝时间 → 遇事件 / 排程结束 / 手动停 → 静止。
>
> 周目的现实长度取决于 **决策次数 × 单次决策时长**，而不是游戏日数。
>
> 【待重算】番茄钟删除后，原先按「轮数」推的时长表全部作废，需要按「每天 3–5 个决策、每次 1–2 分钟」重新估算。见 [12 §2](12-番茄钟与时间系统.md)。

> 若采用周目制，「清档重来」与「回溯 N 天」的互斥问题会自动消解——结局就是这一局结束，不需要回档。

## 7. 行动清单（2026-10-31 定稿）

行动 = 每次消耗 **1 个行动位**。周中每天 2 个、周末每天 2 个（周末含演出）。

### 7.1.1 三条边界

1. **初级免费、中级花钱、高级又贵又伤**——层级越高，风险越大。
2. **中级是唯一能同时练两项的层级**，所以它是性价比最高的分段。
3. **每个属性都能走完全程**，不存在「演技只能靠事件涨」的死角。

| 行动 | 效果 |
| --- | --- |
| 更换城市 | 改变场景池、机会池、粉丝分布 |
| 触发剧情 | 由事件自动进入，占 1 个行动位 |
| 强制任务 | 剧情强制，不可拒绝 |
| 度过节日 | 固定事件，全组合参与 |

### 7.6 社交：不独立成行动

社交不做单独按钮，而是**邀请机制**：

- 部分行动可勾选「邀请同行」（队友 / 朋友）
- 效果：产出加成、触发角色对话、影响组合默契与性格倾向
- 代价：分走部分收益或额外花费

> 这样既保留了「一起做事」的温度，又不会让行动菜单多出一整栏。
