# 《idollife》美术风格提案 — 主角角色

> 版本 v1 ｜ 2026-11-02 ｜ 资产代号 `idol_hero_01` ｜ 露出尺寸：窗口内 260×360，人物页 480×720
> 目标平台：Web（React 18 + Vite，桌面浏览器优先，WebGL 渲染层后加）
> 关联：[01 产品定位](01-产品定位与目标用户.md)（"不做美术"为第一期反需求，本提案是**对其的修订**）· [05 内容与叙事](05-内容与叙事.md)（5 个主角模板）

## 0. 结论先行

1. **她是一个"容器"，不是一个"人设"**——玩家从 5 个模板里选、自己取名、自己描述外观。所以形象的记忆点必须落在**剪影**上，而不是设定符号（伤疤、特定发色、特定职业元素）。剪影在，换成任何人设都不违和。
2. **五件可换 = 20 组素材生成约 1,700 种外观**。素材成本按"部件"算，组合数是免费的——前提是所有部件共用同一套锚点与参数。这一条决定了整个项目的做法，见[规格文档](idollife-美术规格与预算.md)。
3. **建议做到半身（止于大腿中段），不做全身**。裤袜这条需求在半身里依然成立（露到大腿），但省掉约一半分层与绑定工作量。
4. **建议先 L0（静态立绘 + 表情差分）上线验证，L1（半身 Live2D）作为目标形态**。理由见 §6.3：一个纯文字摸鱼游戏引入 WebGL 角色，成本不只是美术。
5. **摸鱼场景有硬约束**：她在屏幕上必须是"最不显眼的那块颜色"。默认低饱和、默认尺寸小、并提供剪影版供"老板键"。

## 1. 风格锚点 v1（逐字复用，生成时整段复制）

```
【风格锚点 v1 — idol_hero_01】
画风：日系半写实赛璐璐，平涂为主，仅 2 档硬边阴影（固有色 / 暗部），不加厚涂笔触
视角：正脸平视，无透视、无仰俯（Live2D 绑定用）；气质参考图可 3/4 侧，但不作为绑定稿
光照：无方向平光（绑定稿）；舞台场景才加一层左侧冷光 + 右侧品红补光
线宽：统一 2px（在 480×720 显示尺寸下量），外轮廓深灰 #2B2A2E，内部结构线同色但 60% 不透明
质感：哑光，皮肤仅鼻头/唇/锁骨三点微弱高光，头发高光为一条断续的弧，不做金属反光
比例：6.5 头身，肩宽 1.4 头宽，头宽:头高 = 1:1.35
色彩倾向：低饱和冷调为主（墨蓝 / 冷灰蓝），皮肤暖白唯一暖源，品红仅作小面积强调（≤8% 画面）
禁忌：不画上挑大眼；不用渐变光晕与体积光；不用纯黑描边；不做写实鼻梁与法令纹；
      不出现偶像产业标识（应援色、真实团体名、真实服装品牌）
```

**自检**：八字段无空项；禁忌 5 条且都能对应具体失败表现（AI 默认输出就是上挑大眼 + 体积光 + 纯黑线）。

## 2. 色彩板

| 角色 | 用途 | 色号 | 明度 L |
|---|---|---|---|
| 主色 | 服装主体 / 主要色块 | `#2E3A4A` 墨蓝 | 22 |
| 辅色 | 服装次级、布料分块 | `#5A6C7D` 冷灰蓝 | 43 |
| 强调色 | 饰品、舞台款、单品点缀 | `#C2546E` 品红 | 52（高饱和，仅小面积） |
| 皮肤 | 脸与四肢 | `#F0D8CD` 暖白 | 86 |
| 背景（暗） | livehouse / 舞台 | `#12161B` | 8 |
| 背景（亮） | 办公室 UI 浅底 | `#E9E5DE` | 91 |
| 描边 / 阴影 | 轮廓与统一暗部 | `#2B2A2E` | 17 |

**硬规则**

1. **皮肤是唯一的高明度暖色**——它是"人"在画面里的锚，任何情况下不得被背景吃掉。
2. 品红只做小面积（发夹、耳饰、舞台服的亮片）。同屏高饱和色 > 3 处即压掉。
3. **发色是变量，不是色彩板的一部分**：6 个可换发色都必须落在 L 10–45 区间（见规格 §1.3），否则缩略图会从"深色人形"变成"浅色块"。
4. 状态不能只靠颜色：体力低不能只把角色调灰，必须配动作（低头、眨眼变慢）。

## 3. 明度阶梯

| 层级 | L 区间 | 角色上的落点 |
|---|---|---|
| 高光 | 82–95 | 皮肤受光面、发丝高光弧（面积 ≤ 3%） |
| 主体亮面 | 65–82 | 脸部亮面、衣服受光面 |
| 中间调 | 42–65 | 服装固有色、发中间调 |
| 暗部 | 22–42 | 颈下、发内层、裙褶、裤袜 |
| 描边 | 10–20 | 外轮廓 |
| 背景 | 6–15（暗）/ 88–94（亮） | 场景 |

**必须处理的一个冲突**：墨蓝衣服 L22 与暗背景 L8 只差 14 点（不到 2 档），黑发 L12 与背景几乎同值。**暗背景下主体会整体糊掉**。解法固定为：

> 暗背景模式：描边 `#2B2A2E` + **外缘 1.5px 冷色边缘光 `#8FA6B8`（不透明度 55%）**
> 亮背景模式：只用描边，不加边缘光。

这条不是可选项。缩略图测试（缩到 10%）时，暗背景下能看见她的唯一原因就是那圈边光。

## 4. 角色设定（可直接照着画）

### 4.1 一句话

> 一个不太会笑、也不太会撒娇的短发女孩，站在小剧场侧幕后面等上场。

### 4.2 造型规格

| 项 | 规格 | 理由 |
|---|---|---|
| 年龄感 | 18–20 | 与 5 个模板（辍学 / 街头 / 上班族 / 剧场女儿 / 陪朋友）都兼容 |
| 身高 | 155cm | 地下偶像常见身高区间；小剧场台阶、特典会视角都好画 |
| 头身比 | 6.5 头身，头高 ≈ 238mm | 半写实；不做 Q 版（Q 版会让"疲惫感"消失） |
| 脸型 | 下颌略收，**不尖下巴** | 尖下巴=精明感，与"没野心"的模板 5 冲突 |
| 眼 | 眼宽 = 头宽 ×0.22，内双，**上眼睑遮瞳孔 1/4，眼角下垂 3°** | 疲惫与克制的全部来源。AI 默认会给上挑大眼，这是首要返工点 |
| 眉 | 平眉，眉尾下压 2° | 不上扬 = 不主动 |
| 鼻 | 只给鼻头阴影 + 鼻翼短线 | 日系惯例；写实鼻梁会破坏平涂 |
| 嘴 | 默认微闭，嘴角**不上扬**；笑是抿嘴笑 | "不会撒娇"的视觉化 |
| 颈 / 肩 | 颈长 0.35 头高、颈粗 0.30 头宽；肩宽 1.4 头宽，锁骨明显 | 瘦 + 肩窄 = 未成年的身体感 |
| 站姿 | 重心在右腿，左肩略低 2° | 不对称才有"活人感"，也给物理一个方向 |

### 4.3 记忆点（剪影层，必须有）

| # | 记忆点 | 层级 | 缩略图可读 | 优先级 |
|---|---|---|---|---|
| 1 | **右前额一绺外翘呆毛**（长度约 0.4 头高，向上外翻） | 剪影 | ✅ | P0 必须有 |
| 2 | **不对称发尾**：左侧内扣到下颌，右侧外翘到锁骨 | 剪影 | ✅ | P0 |
| 3 | 锁骨下一颗小痣 | 细节 | ❌（只有大图可见） | P1 |

**验证方法**：整图涂黑，缩到 10%。如果还能认出"一个短发、右上一撮翘起的女孩"，记忆点成立。认不出就是第 3 条：回去改轮廓，不要靠加细节。

### 4.4 表情（6 个 P0 + 2 个 P1）

| 表情 | 参数要点 | 用在哪 |
|---|---|---|
| 默认 | 眼半开、嘴角平 | 常驻 |
| 微困 | 上眼睑再下压 15%、眉头内收 | 体力低 / 深夜 |
| 抿嘴笑 | 嘴角 +2°、下眼睑上抬、腮红 +20% | 被夸 / 事件成功 |
| 惊讶 | 瞳孔缩 10%、眉抬、嘴微张 | 事件触发 |
| 不悦 | 眉尾下压、视线偏左 | 冲突事件 |
| 紧张 | 眉内端上抬、瞳孔微颤 | 试镜 / 上台前 |
| （P1）喘 | 张嘴、肩抬、呼吸振幅 ×1.8 | 排练后 |
| （P1）哭 | 下眼睑积水高光、鼻头泛红 | 结局 |

### 4.5 不允许出现的（角色层禁忌）

- ❌ 上挑大眼、双眼皮褶皱画满、睫毛成排（会变成"甜系"）
- ❌ 明显的"偶像符号"：应援色发带、爱心发夹成组、星星眼
- ❌ 任何真实团体 / 品牌的服装元素
- ❌ 依赖设定的装饰（纹身、伤疤、特定职业道具）——玩家换模板就穿帮
- ❌ 纯黑描边（在暗背景上会和背景融合成死黑块）

## 5. 三个方向候选

推荐 A。B/C 只在用户明确要"更暖"或"更甜"时切换，切换成本见右列。

| 方向 | 一句话 | 色彩特征 | 与项目基调配性 | 切换成本 |
|---|---|---|---|---|
| **A（推荐）剧场冷光 · 低饱和日常** | 侧幕后的冷光，颜色都"退了一档" | 墨蓝 / 冷灰蓝 / 暖白皮肤 / 品红点缀 | 契合 [05](05-内容与叙事.md) 的"克制、日常、略带疲惫" | — |
| B 暖黄荧光 · 90s 剧场 | 旧海报、颗粒、暖黄灯泡 | 土黄 / 赭红 / 米白，L 整体 +8 | 更"怀旧"，但会更抢眼，与摸鱼场景冲突 | 只改色彩板 + 光照，造型不动；1 天 |
| C 清透日系 · 甜 | 高明度、圆脸、粉紫 | 粉 / 浅紫 / 高明度，L 整体 +15 | 商业上更讨喜，但与"疲惫"基调矛盾，且缩略图辨识度下降 | 改脸型比例 + 色彩板；约 3 天，且已画的部件要重新调色 |

## 6. 表现约定

### 6.1 角色与 UI 同框

- 角色**永不与文字争明度**：正文区域背景 L ≥ 88，角色最亮处（皮肤 L86）不得高于它 3 点以上。
- 角色与面板之间留 8px 空白 + 一条 1px `#00000014` 分隔线，避免"贴纸感"。
- 舞台事件时才允许整体提亮：背景压到 L6，补一层品红，角色边缘光升到 70%。

### 6.2 尺寸与"摸鱼"约束（项目独有，必须遵守）

[01](01-产品定位与目标用户.md) §2.2 明确写了：办公场景里"大幅可识别的绘画"会让玩家被辨认出在摸鱼。Live2D 角色正是全屏最饱和、最大的元素。三条对策，缺一条就违背了产品前提：

1. **默认尺寸 260×360**（约屏幕 12%），不做全屏立绘；
2. **默认低饱和 + 无边缘光**（边缘光只在舞台事件开），降低"这东西在动"的视觉吸引力；
3. **出剪影版**：同一模型导出全黑剪影 + 70% 不透明度的一套贴图，供"老板键"一键切到 40px 缩略剪影。剪影版必须**在绑定时就一并规划**（同网格，只换贴图），不能事后补。

### 6.3 三档形态与取舍（诚实建议）

| 档 | 形态 | 美术工作量 | 技术依赖 | 建议 |
|---|---|---|---|---|
| **L0** | 1 张静态立绘 + 6 张表情差分 + CSS 呼吸/视差 | 2–3 人日 | 无（纯 `<img>` 切换） | **先上这档验证玩家是否在乎视觉** |
| **L1** | 半身 Live2D，20 组可换部件，4 个动作 | 单人 5–7 周（含返工） | 需引入 WebGL + Cubism Web runtime（首次加载 +3–4MB） | **目标形态** |
| L2 | 全身 + 舞台演出动作 + 舞台服 | 再 +6–8 周 | 同上 + 场景系统 | 看 L1 的留存数据再定 |

不支持"先做 L1 再回头补 L0"：L0 的差分图可以直接当作 L1 的表情素材，但反过来不行。

## 7. 禁忌清单

1. 不模仿在世画师个人风格；不生成受版权保护的角色。
2. 不用渐变光晕 / 体积光 / 镜头光斑（会立刻变成"AI 味"）。
3. 不用纯黑描边、不用写实鼻梁与法令纹。
4. 不做上挑大眼、不做成排睫毛。
5. 不做"卖萌"姿态（歪头 + 举拳 + 星星眼）：与"没野心、走一步看一步"的主角冲突。
6. 不在同一张图里混用两种线宽策略（外粗内细 vs 全粗）。
7. 不用高饱和背景（会抢角色，且让缩略图糊）。
