## 本文回答什么

- 组合是什么？为什么演出必须要组合？
- NPC 成员怎么来？重复了怎么办？
- 真人和 NPC 怎么共存于同一个组合？

## 0. 定义

| 概念 | 说明 |
| --- | --- |
| **组合** | 演出单位，人数 **1–10**。一个人也可以是组合 |
| **主角** | 玩家养成的那个偶像，数值完整（04 的八层） |
| **NPC 成员** | 招募来的角色卡，数值简化 |
| **真人成员** | 联机时替换某个 NPC 位 |

- 开局是单人（练习生），出道期开始组建组合
- 不管几个人，「演出」这个动作必须在组合框架下发生

## 1. 成员三类

| 类型 | 来源 | 数值范围 | 可养成 |
| --- | --- | --- | --- |
| 主角 | 玩家 | 完整八层 | ✅ 全部 |
| NPC 成员 | 招募 | 4 能力 + 定位 + 相性倾向 + 熟练度 | ❌ 只随重复提升 |
| 真人 | 联机 | 与 NPC 同一水平线（场次修正） | — |

> NPC 不需要单独养成——这省掉一整套「练卡系统」，也避免「练主角还是练卡」的纠结。

## 2. NPC 的水平线

**核心规则：NPC 的总强度跟随玩家当前养成度，差异只在偏向。**

| 项 | 规则 |
| --- | --- |
| 基准 | NPC 初始 = 主角当前水平的 **90%** |
| 上限 | 重复加成最多 +10%，即最高约 **99%**——追平但不反超 |
| 差异 | 属性偏向不同：唱型 / 跳型 / 演型 / 口才型 / 均衡型 |
| 稀有度 | **无**——招募到的都是「不同形状」，不是「更强的数值」 |

好处：招募不会破坏养成平衡，玩家买的是**搭配可能性**。

## 3. 招募

| 项 | 规则 |
| --- | --- |
| 名称 | **招募**（不是抽卡）——叙事上是「找星探 / 试镜」 |
| 花费 | 游戏内金钱，不涉及付费 |
| 产出 | 随机获得一个 NPC |
| 池子 | 【待确认】有限池（如 20–30 人，招完为止）还是随进度无限生成 |
| 入口 | 组合页 → 招募 |

> 用「招募」而不用「抽卡」：避免玩家按传统 gacha 的预期理解（几星、概率），也贴合地下偶像的叙事。

## 4. 重复招募

招募到已有 NPC 时：

```
该 NPC 全部属性 × (1 + 1% × 重复次数)
```

- 永久生效，是长期目标
- 不设稀有度，所以「重复」不是浪费，而是**给这个角色补课**

> 【已定】上限 **+10%**。因为基准是 90%，所以重复拉满 ≈ 99%——刚好追平主角，永远不反超。
> 这样联机时「真人替换 NPC」才有意义：真人也在同一水平线上，不会因为 NPC 太强而没人愿意替。

## 5. 阵容配置

| 项 | 规则 |
| --- | --- |
| 上场人数 | 1–10，由演出类型决定上限 |
| 定位 | 主唱 / 副唱 / 舞担 / 门面 / 综艺位 |
| 人数影响 | 【待填】加分、稀释、短板惩罚的比例 |
| 保存 | 记住上次阵容，一键复用 |

## 6. 联机替换

- 演出报名后，某个 NPC 位可以由真人玩家替换
- 替换者的属性按**场次档位**修正（见 [18 §6](18-联机与异步结算.md)）
- 收益分配：【待填】双方各得，还是按贡献分

## 7. 与经济的关系

| 出口 | 说明 |
| --- | --- |
| 招募费 | 每次招募花钱，形成持续消耗 |
| 重复转化 | 重复也有价值 → 玩家愿意持续招募，钱有地方去 |

## 8. 主角的生成（2026-10-30）

主角不是凭空捏的，**和 NPC 用的是同一个模板池**：

| 步骤 | 内容 |
| --- | --- |
| 1. 选模板 | 决定基础属性 + 隐藏属性（性格 / 负向，只通过简介模糊透露） |
| 2. 选初始条件 | 处境二选一：家底薄 / 有点积蓄 / 有人照应 / 白纸一张 |
| 3. 配置 | 名字、外观描述 |
| 4. 进入 | 以练习生身份开局 |

- **模板池共用**：主角能选的，招募也能招到——区别只在「可不可养成」
- 模板是**多周目的差异来源**：换模板 = 换一副牌重开
- 详细的人设与简介写法见 [05 §2](05-内容与叙事.md)
