## MVP 边界（一句话）

> MVP = 玩家能在网页上完成 **「专注 → 训练 → 接一次通告 → 拿到钱 → 数值变高」** 这一整圈，关掉浏览器再打开进度还在。

【待填】按你的想法修正这句话——它会被直接当成 [13 里程碑](13-里程碑与迭代.md) 的验收口径。

> 联机（S16–S18）**不进 MVP**，但 MVP 的数据模型必须能对接它：结算函数纯函数化、属性可序列化、时间统一走 `clock` 接口。见 [18 §10](18-联机与异步结算.md)。
