## 本文回答什么

- 这个游戏「讲什么」？基调是甜、是苦，还是平淡真实？
- 玩家在哪看到文字？事件、日志、消息、还是社交媒体流？
- 文本怎么生产、怎么进游戏、怎么维护？

## 0. 内容定位

原始文档写的是「**拟真偶像生活**」，且**无美术**——意味着**文字承担了全部的表演**。这是本项目最大的内容风险，也是最大的差异化机会。

【待填】用三个词定基调：______、______、______（例：克制、日常、略带疲惫）

## 2. 主角模板（2026-10-30 定稿）

主角从模板里选。模板 = **人设 + 属性偏向 + 初始性格倾向**，选定后再配置名字与外观。

| # | 人设（一句话） | 属性偏向 | 性格倾向 | 优势 | 代价 |
| --- | --- | --- | --- | --- | --- |
| 1 | 背水一战：辍学来东京，只剩这一次机会 | 演唱 | 独立↑ 好强↑ | 演唱起点高 | 起始资金少 |
| 2 | 天赋型：街头被星探发现，从没受过训练 | 舞蹈 | 热情↑ 合作↓ | 舞蹈上限高 | 基础低，初期容易崩 |
| 3 | 白天上班晚上练习：有稳定收入，但时间少 | 口才 | 合作↑ 好强↓ | 资金稳定、口才好 | 体力上限低 |
| 4 | 剧场家的女儿：从小在后台长大 | 演技 | 体贴↑ | 演技起点高、有人脉 | 舞台实战经验少 |
| 5 | 陪朋友试镜被选上：没野心，走一步看一步 | 均衡 | 随机 | 没有短板 | 也没有长板 |

> 模板是**多周目的差异来源**：换模板 = 换一副牌重开。
> 这 5 个是草案，人设可以随便改——关键是**每个模板都要有一个明确的取舍**，不能有纯上位选项。

三条关键规则：

1. **模板池与招募共用。** 主角选模板，NPC 招募也从同一个池里出——区别只在于主角可以养成，NPC 跟随水平线。
2. **模板差异 = 基础属性 + 隐藏属性。** 隐藏属性（性格 / 负向）**不显示数值**，只通过「人物简介」的几句话模糊透露。
3. **选完模板还有第二层抉择：初始条件。** 见下节。

#### B. 初始隐藏倾向（只写文字，不给数值）

| 处境 | 隐藏倾向 |
| --- | --- |
| 孤身沪漂 | 独立强、抗压高；但「无退路」，精神压力涨得快 |
| 小小二代 | 从小见惯场面，不怯场；但被质疑「靠家里」，好强偏弱 |
| 平平无奇 | 没有特别的天赋，也没有特别的伤 |
| 声乐生 | 好强、完美主义，容易把自己的标准压在身上（焦躁↑） |
| 舞蹈生 | 热情高、服从性好；文化课弱，在采访类场合吃亏 |
| 表演生 | 共情强（体贴↑）；但舞台怯场，首演容易失手 |
| 播音生 | 领导力强、表达稳；唱歌时放不开（演唱成长偏慢） |
| C站舞见 | 习惯一个人练（合作↓）；对弹幕评价敏感（焦躁↑） |
| 前 OTA | 抗压极强、会看人脸色（体贴+合作↑）；有年龄焦虑（精神压力） |
| 保持运动 | 自律，负向增长慢；但太习惯独处（合作↓） |
| 二次出道 | 舞台熟练度高、抗压；黑历史在身，粉丝期待高（压力） |
| 主播 | 会说话、情绪稳；习惯即时反馈，耐心偏低 |
| 短剧演员 | 入戏快（体贴、热情↑）；不习惯现场，舞台评分偏低 |
| 大一新生 | 成长快、恢复快；时间被课表切碎，缺钱 |
| 上班族 | 稳定、隐忍（体贴↑）；长期疲惫，体力恢复慢 |
| 程序员 | 逻辑强、抗压；社交弱（合作↓），作息乱（体力低） |

> 16 个处境 × 5 个模板 ≈ 80 种开局。
> 每条都必须有**真实代价**：只要有一条看起来永远更优，玩家就会固定选它，多周目立刻失去意义。

> 两类抉择叠加，等于「人 × 处境」的组合——这是重开的主要变量来源。
> 【待确认】初始条件是否也可以有 4 个以上、是否与模板有互斥关系。

### 2.2 隐藏属性怎么透露

人物简介固定 **3 句**，其中 1–2 句暗示隐藏属性，但不给数值：

| 简介写法 | 暗示 |
| --- | --- |
| 「她总在排练室留到最晚」 | 好强高、积劳风险 |
| 「被夸的时候会低头笑」 | 体贴高、独立低 |
| 「试镜前一晚没睡着」 | 焦躁偏高、精神偏低 |

玩家读简介就像在「看人」——选的是感觉，不是面板。

## 3. 结局结构（2026-10-30）

生涯固定 **游戏内 2 年**。第 2 年尾声触发「留圈抉择」，随后进入结局。

### 3.1 判定流程

```
生涯第 2 年尾声
   │
   ├─ 玩家抉择：留在娱乐圈？
   │      ├─ 留在台前 → A1 粉丝型 / A2 属性型 / A3 未达标

   │      └─ 离开     → B 组（职业 / 人生 / 坏结局）
```

### 3.6 判定：三轴组合

结局不看单一数字，看**三条关系的形状**。三轴各分三档：低 / 中 / 高。

| 轴 | 本质问题 | 组成 |
| --- | --- | --- |
| **自我** | 她还是她自己吗 | 意愿、事件抉择、性格 |
| **他人** | 别人怎么看她 | 事件、隐藏属性、粉丝情况、负向属性 |
| **适配** | 她够不够格 | 属性、状态、熟练度、经历 |

组合决定**去向**，去向内再按粉丝构成或峰值属性定具体结局：

| 自我 | 他人 | 适配 | 去向 |
| --- | --- | --- | --- |
| 高 | 高 | 高 | A（台前：粉丝型 / 属性型） |
| 高 | 高 | 中 | A（台前：粉丝型） |
| 高 | 高 | 低 | A3 未达标 |
| 高 | 中 | 高 | A（属性型优先） |
| 高 | 中 | 中 | A（粉丝型） |
| 高 | 低 | 高 | A4 转幕后 / 清冷名伶 |
| 高 | 低 | 低 | A3 角落伴舞 |
| 中 | 中 | 中 | B2 平淡是福 |
| 中 | 中 | 高 | A（属性型） |
| 中 | 低 | 中 | B（职业类） |
| 低 | 高 | 高 | A（粉丝型：昙花一现向） |
| 低 | 高 | 低 | A3 腰部网红 |
| 低 | 低 | 高 | B3 人走茶凉 |
| 低 | 低 | 低 | B3 潦倒收场 / 急流勇退 |

> 三轴是**档位**不是分数：玩家只会被告知"高/中/低"，算不出精确值，也没法刷。

#### 三轴怎么被玩家感知

| 项 | 规则 |
| --- | --- |
| 界面显示 | **不显示**；通过「半年评价事件」和**付费占卜**获知 |
| 揭示方式 | **每游戏半年**触发一次「评价事件」 |
| 形式 | 一封评价：社长 / 经纪人 / 媒体 / 粉丝信，三句话分别点出三轴 |
| 示例 | 「你眼里还有光」（自我高）｜「剧场开始有人点你的名字」（他人中）｜「但你的舞还差一口气」（适配低） |
| 作用 | 让玩家知道自己走到哪了，但不能精确计算 |

> 半年一次，一个 2 年周目只出现 3–4 次。**每次都是一次校准**，而不是仪表盘。
> 想随时知道自己走到哪了，就花钱占卜——**免费定期 + 付费随时**。

## 4. 事件结构（2026-10-30）

### 4.1 三类事件

| 类型 | 触发方式 | 2 年总量 | 生产方式 |
| --- | --- | --- | --- |
| **常规事件** | 每 **1–3 次行动**出现一次 | **500–700** | **模板生成**（变量填充） |
| **固定事件** | 节日 / 固定日期 | 20–30 | 手写 |
| **剧情事件** | 属性触发为主、流程为辅 | 40–60 | 手写 |

### 4.2 为什么常规事件必须模板化

2 年 = 104 周 × 14 行动 = **1456 次行动**。
每 2 次行动一个事件 → **728 个事件**。

手写 728 个是不可能完成的，所以：

> **常规事件 = 模板 × 变量**，不是一段一段写出来的。

模板池设计：

| 维度 | 取值 |
| --- | --- |
| 场景 | 排练室 / 便利店 / 车站 / 后台 / 街头 / 宿舍 |
| 对象 | 队友 / 粉丝 / 路人 / 工作人员 / 家人 |
| 结果 | 状态微涨 / 小摩擦 / 灵感一闪 / 疲惫 |

- 6 场景 × 5 对象 × 4 结果 = **120 种组合**
- 再叠加变量（人名、数值、时间）→ 足以覆盖 700 次而不明显重复

### 4.3 剧情事件的触发

| 触发源 | 说明 | 优先级 |
| --- | --- | --- |
| **属性阈值** | 某项属性首次达到 X | 主 |
| **负向阈值** | 积劳 / 精神 / 情欲 突破 | 主（危机类） |
| **流程节点** | 阶段推进、留圈抉择 | 辅 |

### 4.4 事件对三轴的影响

| 类型 | 自我 | 他人 | 适配 | 是否改数值 |
| --- | --- | --- | --- | --- |
| **常规** | — | — | — | ✅ **只改数值** |
| **固定** | 中 | 中 | 微 | ✅ |
| **剧情** | **大** | 中 | 中 | ✅ |

> **三轴只由「有重量的选择」改变。** 常规事件是生活的噪音，只动属性——不然玩家会觉得「我随便逛个便利店就变了个人」。

## 5. 叙事载体

| 载体 | 用途 | 频率 | 长度 |
| --- | --- | --- | --- |
| 行动结果文本 | 每次行动的即时反馈 | 高 | 1–3 句 |
| 事件卡 | 条件触发的剧情 | 中 | 5–20 句 |
| 消息 / 私信 | 角色互动、氛围 | 中 | 1–5 句 |
| 社交动态流 | 世界观补充、粉丝反应 | 高 | 1–2 句 |
| 阶段结算 | 回顾与成长感 | 低 | 一段 |

【待填】是否要做「社媒模拟」？纯文字下它性价比很高（数据即内容）。
