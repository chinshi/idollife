## 0. 已知前提（来自需求源头，不需重复论证）

- Web 版；**美术放开**（原「无美术 / 纯文字」反需求已作废，见 16 D-015）
- 定位：**沉浸式地偶养成**——陪一名地下偶像走完从练习生到生涯结局的完整两年（原「上班摸鱼场景」已废弃，见 16 D-015）

## 1. 一句话定位

【已定】一款沉浸式的地下偶像养成游戏：玩家以经纪人身份陪一名地偶走完两年生涯。慢节奏、重叙事 —— 排程后自动流逝，离线世界照常运转，回来读「你不在时发生了什么」。

## 2. 目标用户

### 2.1 用户画像

|画像|可用时段|单次时长|核心诉求|会流失的原因|
|---|---|---|---|---|
|剧情型|晚上 / 周末|20–40 分钟|被故事牵着走、人物有血有肉|文本空洞、事件重复|
|养成型|通勤 / 睡前|15–30 分钟|看着她一点点变强|成长无感、数值通胀|
|放置型|碎片 + 每天回归|5–15 分钟|挂机有进展、回来有惊喜|离线没补偿、回来无事可做|
|二周目型|整块时间|30 分钟以上|换条路走、看不同结局|结局单一、重开无新意|

> 不再按「上班 / 会议 / 工位」划分画像：产品不再为「不被发现」设计，而是为「愿意投入一段完整时间」设计。

### 2.2 需求推导（每条都要能推出一个设计约束）

- 因为**玩家要的是「一段人生」而不是「一串数值」**，所以叙事优先于数值反馈：结算先给「发生了什么」，再给变化量。→ 见 [08 §1 叙事沉浸](08-沉浸体验与节奏.md)
- 因为**两年生涯要有起承转合**，所以节奏必须分段：生存期（密）→ 出道期（赌）→ 养成期（疏而重）。→ 见 [02 §5.1](02-核心玩法与循环.md)
- 因为**玩家不可能一直盯着屏幕**，所以时间由排程推进而非在线时长；离线期间世界照常运转，回来补战报。→ 见 [12](12-时间系统.md) 与 [18](18-联机与异步结算.md)
- 因为**抉择要让人记得住**，所以关键抉择不提供撤销，后果跨阶段可见（结局、关系、口碑）。→ 见 [02 §6](02-核心玩法与循环.md)
- 因为**沉浸需要氛围而不只是文字**，所以美术放开：立绘 / 色调 / 动效承担情绪表达，视觉随成长阶段递进。→ 见 [美术风格提案](idollife-美术风格提案.md) 与 [T-018](../collab/T-018-成长阶段体系与晋级交互.md)

> ⚠️ **2026-11-03 清理**：原「不能有美术（怕被认出摸鱼）」「番茄钟是关键差异点」「单次操作必须足够短」三条推导已随 D-015 / D-009 删除。
> 「随时可离开、离开不惩罚」作为**体验承诺保留**，但理由改为「世界连续性」而非「怕被老板叫走」，见 [08 §4](08-沉浸体验与节奏.md)。

## 3. 竞品与参照

|参照对象|学什么|不学什么|
|---|---|---|
|旅行青蛙|低频、留白、回来有惊喜|过度被动、玩家没有决策|
|偶像大师 / 偶像梦幻祭|属性成长与舞台反馈|重抽卡、重肝|
|放置类（Melvor Idle 等）|长时间轴成长|数值膨胀、无限堆叠|
|文字冒险 / 视觉小说|叙事密度与抉择分量|线性、无经营层|

银河奶牛-学页面样式、数值 不学高频操作、过于复杂系统

喵国建造者-学页面样式、玩法  不学简单重复、缺少选择和判断

## 5. 成功指标

|指标|目标（上线首月）|为什么看它|
|---|---|---|
|次日留存|60%|验证「明天还想回来」|
|单次会话时长|15–30 分钟（期望值）|验证是否进入沉浸区间，而不是随手点两下|
|单次会话内的事件阅读率|【待填】|验证叙事是否真被读，而不是被跳过|
|单日决策次数 / 人|【待填】|验证「排程 + 自动流逝」是否被使用|
|赞助转化率|【待填】|验证免费模式能否自持|
|大演出参与率（联机上线后）|【待填】|验证异步联机是否真的成为留存钩子|
|周结算回访率|【待填】|周日回来领奖的人有多少|
