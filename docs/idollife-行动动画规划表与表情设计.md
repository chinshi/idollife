## 1. 三条硬前提（写动画之前必须认）

### 1.1 参数表里没有手臂 / 腿部参数

规格 §2.2 的 25 个参数只有：头 `ParamAngleX/Y/Z`、身体 `ParamBodyAngleX/Z`、升降 `ParamBodyY`、呼吸 `ParamBreath`、眼 / 眉 / 嘴、发组 / 呆毛 / 马尾、裙摆 `ParamSkirt`、腮红 `ParamCheek`。**没有 `ParamArmL/R`、没有腿部 IK。**

因此下表所有「抬手 / 挥手 / 递物 / 擦桌 / 摆臂」都**不是真动手臂**，一律按三种替代手法实现：

| 替代手法 | 做法 | 成本 |
|---|---|---|
| A 身体倾斜带出 | `ParamBodyAngleZ` ±3–8° + `ParamBodyY` 升降，手臂 ArtMesh 挂在同一个变形器上被动跟摆 | 0（B2a 绑定时挂点搞定） |
| B 头部与视线补位 | `ParamAngleX/Y/Z` + `ParamEyeBallX/Y` 让「朝向 / 注意点」明确，观感上补足手部意图 | 0 |
| C 物理二次动 | 马尾 L/R、前发、呆毛、裙摆 `ParamSkirt` 的滞后摆动，给动作重量感 | 0（已在 7 组物理里） |

> **给 B2a 的硬约束**：手臂 / 小圆手 ArtMesh 在绑定时必须挂到 `ParamBodyAngleZ` 驱动的变形器上（重叠区 10–15%），**不新建参数**。否则本表 24 段全部做不出来，或被迫改参数表导致连锁重调。
> `ParamBodyAngleX` 范围仅 −10..10，**不能做「转身」**，只能做「侧身 ≤8°」。

### 1.2 帧率口径桥接（别把序列帧规范硬套到 Live2D）

本项目是**参数曲线动画**（Cubism `.motion3.json`），不是序列帧。动画规范里的「8/12/15 帧率档位、`frame_check.py`、精灵表」只对**将来若出现序列帧特效**才适用。这里取：

| 项 | 取值 | 说明 |
|---|---|---|
| 采样率 | **30 fps**（档位内） | Cubism 导出曲线采样，不是逐帧画 |
| 时长 | 2.0–5.0 s（随机） | 段级基准见 §3，调度器再加 ±0.3s 抖动 |
| 每段关键帧 | **6–10 个** | 预备 2 / 主体 2–3 / 收势 3–4；不是 60–150 张画 |
| 三段节奏 | 预备 **30%** / 主体 **15%** / 收势 **55%** | 落在规范 25–35 / 10–20 / 45–60 区间内 |
| 循环点 | **无**（非循环），`hold_last` 0.15 s 后回 idle | 例外：进食 / 打盹的呼吸与咀嚼可在段内设局部 `loop_start/end` |
| 根位移 | **不做**，位移交代码 | 规范硬约束，循环动作同理 |

> 2.5 头身小圆手**拿不住东西**：麦克风 / 碗 / 扫帚一律不画（若画，每件 = 新贴图 + drawable + 图集占用，且要新建参数）。用姿态暗示即可。

### 1.3 冻结顺序

`B2a`（分层 + 25 参数 / 7 物理 / 变形器树冻结，含 B1 红格打歌服裙摆网格）→ `B2b`（本表 24 段）→ `B2c`（其余装备挂到同一棵树）。**先冻结再打帧**，否则衣服不跟着身体晃，24 段全要重调。

### 3.1 帧事件与状态机接口（24 段统一，不逐段写）

| 接口 | 取值 | 说明 |
|---|---|---|
| `exp_frame` | 预备段末（≈30% 处） | 切到主表情；随机池表情在 `exp_frame` 前由调度器选定 |
| `cancel_from` | **收势段起点（≈45% 处）** | 此后允许下一条行动打断，0.2 s 淡出到新段；与倍速（8× 约 3.75 s/行动）配套 |
| `sfx_frame` | 主体段首（≈30% 处） | 可选，建议给歌唱 / 舞台段配 |
| `loop` | 无；`hold_last` 0.15 s → 回 `idle` | 例外：`REST_02` 咀嚼、`REST_01/03` 呼吸可在段内设局部循环点 |
| `move_delta` | **0** | 循环规范：根位移交代码 |
| 状态集 | `idle` → `action` → `idle` | 中断优先级：`action` 可被下一条 `action` 打断（仅 `cancel_from` 之后）；`idle` 最低 |
| 随机种子 | 接 `seed:action:<行动id>`（D-010） | 前端动画随机与服务端结算共用同一 seed，保证回放一致 |

### 5.3 给 B2a 的两条分层约束

### 5.4 表情与行动的匹配原则

| 原则 | 说明 |
|---|---|
| 情绪由行动语义定，不由类别定 | 同为 `work`，女仆咖啡是抿嘴笑、发传单是微困；同为 `recover`，漂亮饭是欢呼、去医院是虚弱 |

## 6. 随机层与调度规则（0 增量，把 24 段做出 48+ 观感）

| 层 | 变量 | 取值 | 成本 |
|---|---|---|---|

| 视线 / 重心层 | `ParamEyeBallX/Y`、`ParamBodyAngleZ` 幅度 ±15%、相位随机 | 与表情层独立随机 | 0 |
| 节奏层 | 时长 2.0–5.0 s 抖动 ±0.3 s、起势快慢、马尾 L/R 相位差 0.15 s | 与上层独立 | 0 |
| 物理层 | 呆毛 / 马尾 / 裙摆摆幅 ×0.8–1.2 | 由 7 组物理自然产生 | 0 |

**调度器规则**（B2b 程序侧，含在 4 人日内）：
1. 按 `行动 ID` → 查族 → 查段池 → 用 `seed:action:<行动id>` 派生选段与选表情；
2. 同一段不连播两次（记录上一次段 ID）；
3. 动画**不阻塞**行动流程；新行动到达时，若当前已过 `cancel_from`，0.2 s 淡出切新段，否则等 `cancel_from` 到点再切；
4. 可跳过 / 可关闭（复用「老板键 / 灰度模式」开关位）；
5. 播完 `hold_last` 0.15 s → 回 `idle`，0.2 s 淡出衔接。
