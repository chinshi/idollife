> 英文值是**代码字段名**，不要改；中文是**显示名**，可以改。

## 6. 触发条件（events.story.requires）

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| `statsAtLeast` | 属性 ≥ 某值 | `{ "dance": 15 }` |
| `axesAtLeast` | 三轴 ≥ 某值 | `{ "others": 45 }` |
| `axesBelow` | 三轴 < 某值 | `{ "fit": 34 }` |
| `staminaBelow` | 体力 < 某值 | `20` |
| `fansAtLeast` | 某类粉丝 ≥ 某值 | `{ "stage": 50 }` |
| `flagsNot` | 这些标记不存在才触发 | `["ev:first-audition"]` |

## 维护约定

1. **英文值 = 代码字段名**，一旦发布就不要改（存档里记的是它）
2. **中文名可以随便改**，只影响显示
3. 新增枚举值：先改这张表 → 再改配置表 → 最后改代码里的类型定义
