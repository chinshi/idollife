## 本文回答什么

- 三十多个数值，怎么分到几屏里还不让人晕？
- 每一屏，玩家是带着什么目的打开的？
- 隐藏数值（性格、负向、熟练度）怎么让玩家「感觉得到」？

## 0. 分层原则

**按玩家的目的分页，不按数据层分页。** 玩家不会想「我要看 L3 隐藏心理」，只会想「我该接这个活吗」。

## 1. 页面地图（2026-10-29 定稿）

结构：**常驻 4 入口 + 临时 4 流程页 + 角落 2 项**。

原则：常驻只放「瞄一眼就要看」的，低频功能一律做成临时页。

### 1.1 常驻入口

| tab | 玩家来干什么 | 内容 |
| --- | --- | --- |
| **主界面** | 我现在该做什么 | 游戏时间、排程、待办、日志、通告入口 |
| **人物** | 我在变强吗 | 基础信息、4 项能力、3 项状态 |
| **能力** | 我擅长什么 | 熟练度、粉丝数、6 类相性 |
| **背包** | 我有什么、多少钱 | 金钱、装备、道具、商店入口 |

### 1.2 临时全屏（用时出现，用完退回）

| 页 | 触发 | 内容 |
| --- | --- | --- |
| 演出配置 | 报名演出 / 周末 | 曲目、服装、定位、预估评分、相性、手感 |
| 占卜 | 主界面按钮 | 性格倾向、负向预警（模糊） |
| 事件抉择 | A 级事件触发 | 事件文本 + 选项 |
| 结局 / 生涯回顾 | 周目结束 | 结局文案、关键选择回放、多周目统计 |

### 1.3 角落

| 项 | 内容 |
| --- | --- |
| 设置 | 字号、深色、老板键、音效 |
| 存档 | 保存 / 读取 / 导入导出 |

> 为什么不做 6 个平铺 tab：摸鱼玩家打开页面是「瞄一眼」，入口越多第一屏越挤。而「演出配置」本来就不是常驻功能——没人会没事去翻它。

## 2. 各页细节

### 2.1 人物页

| 区块 | 字段 | 显示方式 |
| --- | --- | --- |
| 基础信息 | 身高、体重、样貌、身材比例 | **描述式**：「高挑」「纤细」「清秀」 |
| 成长属性 | 演唱、舞蹈、演技、口才 | 数字 + 进度条（0–100） |
| 状态 | 体力、心情、饱腹 | 数字 + 图标 |

### 2.2 能力页

| 区块 | 显示方式 |
| --- | --- |
| 熟练度（场所 / 歌曲 / 舞蹈） | **定性三档**：生疏 / 熟练 / 精通 |
| 粉丝总数 | 数字——当前「名气」的唯一衡量 |
| 粉丝相性（6 类） | 等级：强 / 中 / 弱（不显示百分比） |

### 2.3 演出 / 行动配置页（决策页）

这一页只放**影响本次决策**的信息：

| 必须显示 | 说明 |
| --- | --- |
| 曲目 / 服装 / 定位 | 可选项与当前选择 |
| 消耗 | 体力、金钱、行动位 |
| 预估评分 | 区间而非确定值（「预计 A–B」） |
| **相性预估** | 这场会吸引哪类粉丝（↑ 现场、→ 舞台） |
| **手感** | 熟练度的定性提示（略顺 / 很顺 / 极顺） |

> 原则：**决策页不放「跟我没关系」的数**。成长曲线、历史记录都退到二级页。

### 2.4 占卜页（隐藏状态的窗口）

隐藏属性不能直接看，但玩家需要"知道自己怎么了"。占卜就是那个窗口：

| 项 | 规则 |
| --- | --- |
| 消耗 | **每次花金钱**；同一游戏日第 2 次起价格翻倍 |
| 频率 | 不限次数，但受金钱限制 |
| 产出 | ① **三轴档位**（自我 / 他人 / 适配：低 / 中 / 高）② 性格与负向的一句模糊提示 |
| 示例 | 「你最近气色不太好」→ 积劳偏高；「你有点心浮」→ 焦躁偏高 |
| 性格 | 「你看起来挺会照顾人」→ 体贴倾向 |

> 设计目的：**让隐藏属性可操作，但不被数值化。** 玩家能据此调整，却算不出精确公式。

### 2.5 商店与通告

**商店**（挂在背包下）：

| 区块 | 内容 |
| --- | --- |
| 今日推荐 | 1 件稀有 |
| 常备货架 | 普通 3–5 件，每**游戏内周**刷新 |
| 已解锁品类 | 随阶段增加 |

**通告列表**（从主界面进入）：

| 列 | 说明 |
| --- | --- |
| 标题 / 类型 | 录音、综艺、影视… |
| 消耗 | 体力、行动位 |
| 预估收益 | 钱 + 吸引哪类粉丝 |
| 门槛 | 需要的能力值或粉丝数 |

## 3. 显示策略总表

| 数据层 | 显示方式 | 例子 |
| --- | --- | --- |
| L0 固有 | 描述词 | 「高挑」 |
| L1 成长 | 数字 | 演唱 32 |
| L2 状态 | 数字 | 体力 62/100 |

| L5 粉丝相性 | 等级 | 「现场：强」 |

## 5. 交互原则

1. **一屏一个决策**：不打多任务。
2. **文字即界面**：用缩进、分隔线、`【】`标签代替图形。
3. **不依赖颜色**：色盲可用。
4. **随时可停**：没有必须等待的动画。
5. **键盘可达**：数字键选行动，`Esc` 收起。

## 6. 响应式

| 断点 | 布局 |
| --- | --- |
| ≥ 1024px | 三栏（状态 / 排程 / 日志） |
| 768–1023px | 两栏 |
| < 768px | 单栏，分段滚动 |
