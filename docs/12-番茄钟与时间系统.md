## 本文回答什么

- 游戏内时间由什么推进？推进多快？

## 0. 为什么废弃番茄钟

一句话：**番茄钟要求「人在场专注」，而本作的核心机制是「提前规划 → 自动流逝 → 没规划就静止」，两者互斥。**

选了自动流逝，就必须放弃「以专注时长驱动成长」。原来的 25 分钟一轮、长短休、连击奖励，全部移除。

## 1. 时间推进模型

```
[玩家排程] → [自动行动 + 时间流逝] → [遇到事件 / 排程结束 / 玩家手动停] → [回到静止]
```

三种状态：

| 状态 | 含义 | 玩家在做什么 |
| --- | --- | --- |
| **静止** | 时间不走，等决策 | 看状态、做选择、排程 |
| **流逝中** | 按排程自动执行 | 可以走开；回来直接看结果 |
| **中断** | 遇到事件或玩家按停 | 决策，然后继续或改排程 |

关键性质：**时间只在「有排程」时流逝。** 玩家不安排，时间就停——这正是「不惩罚缺席」的实现方式。

## 2. 时间粒度

同一段游戏内时间，在不同阶段由不同的行动跨度覆盖（详见 [02 §5](02-核心玩法与循环.md)）：

| 阶段 | 一个行动推进 | 说明 |
| --- | --- | --- |
| 生存期 | 1 游戏日 | 每天都关键，决策密 |
| 出道期 | 数日 – 1 周 | 开始出现「排程跑几天」 |
| 固定成员 / 人气成员 | 1 – 4 周 | 排程一次跑一段，事件打断 |

> 【待填】养成期的行动跨度最终取多少（1 周 / 2 周 / 1 月），影响周目总轮数。

## 3. 真实时间 ↔ 游戏时间（2026-10-31 修订）

**时间跟着现实时钟走**，但只在「有排程」时推进：

| 状态 | 时间是否推进 |
| --- | --- |
| 有排程 + 页面开着 | ✅ 按行动消耗推进 |
| 有排程 + **页面关着** | ✅ **继续推进**（这就是排程的意义） |
| 排程跑完 / 没排程 | ❌ 静止 |

- 游戏时间与现实时间的换算由「行动耗时」决定（1 行动 = 10 分钟游戏时间）
- **离线期间**：服务器按 `lastSyncAt` 重放排程，排程耗尽即停
- 存档记录 `lastSyncAt` 与当前排程队列

| 事件 | 处理 |
| --- | --- |
| 关页面 | 排程继续跑，跑完停在终点 |
| 电脑休眠 | 同上（按真实流逝计算） |
| 断网 | 本地按确定性模拟继续，重连后服务器重放校验 |
| 改系统时间 | **无效**：以服务器时钟重放排程 |
| 长时间不登录 | 排程跑完即静止，进度不丢 |

> ⚠️ 因为时间跟现实走，**必须做服务端校验**（见 [09 §4.2](09-技术选型.md)）。校验点只在**行动完成**等关键节点，不做连续校时。

## 4. 什么会打断自动流逝

| 情况 | 是否打断 |
| --- | --- |
| 排程跑完 | ✅ |
| 触发事件（剧情、通告、危机） | ✅ |
| 资源见底（钱、体力） | ✅ |
| 玩家手动按停 | ✅ |
| 切标签页 / 锁屏 | ❌ 继续跑 |

> 断点即决策点。**每一次打断都是一次「值得让玩家看一眼」的时刻**，否则不该打断。

### 4.1 事件抉择：怎么保证不漏（2026-10-29）

核心规则：**影响结局的抉择，必须让时间冻结。**

```
事件触发 → 时间立即停止 → 玩家决策 → 选择生效 → 时间恢复
```

因为时间是「无排程即静止」，所以玩家不在场时，世界就停在事件发生前——**不存在「回来发现已经错过」**。

事件分三级：

| 级别 | 例子 | 处理 | 是否暂停 |
| --- | --- | --- | --- |
| **A 关键** | 影响结局走向（出道机会、丑闻、解散危机） | 强制暂停，等玩家 | ✅ |
| **B 次要** | 影响数值（临时通告、粉丝抱怨） | 写进日志，不打断，可事后处理 | ❌ |
| **C 琐事** | 纯氛围（路人评论、天气） | 自动处理 | ❌ |

防「暂停疲劳」：

- 每天最多 **1–2 次** A 级暂停
- 两个 A 级事件之间至少隔 **1 个游戏日**
- 同一时刻多个事件合并成一次「决策组」

两条与「不漏」直接相关的规则：

1. **事件永不超时。** 不设倒计时，系统**不会替玩家做决定**。世界等你。
2. **选择必须留痕。** 每个 A 级选择记入「生涯记录」，结局时回放关键节点——让玩家看得见「我选了什么、导致了什么」。

> 玩家 24 小时不处理时：世界保持静止，界面只显示「有 1 件事等你决定」。不催、不罚、不跳过。

## 5. 与联机的关系

联机的场次与截止时间是**服务器时间**，与本地游戏时间解耦。玩家本地怎么跑，都不影响演出结算的钟。

## 6. 待确认

- 【待填】养成期一个行动推进多久（1 周 / 2 周 / 1 月）
- 【待填】自动流逝的速度：秒级即时跑完，还是有「加速播放」的观感
- 【待填】一次排程最多排多少个行动
- 【待填】时间静止时，界面显示什么（停在哪一天？还是模糊显示）
