## 本文回答什么

- 一共哪些数值？分成几层？谁影响谁？
- 演出评分、粉丝相性怎么算？
- 这么复杂的东西，怎么让摸鱼玩家看得懂？

## 0. 设计立场

**系统要复杂，界面要简单。** 复杂度做在系统里，不摊在玩家脸上。

- 主界面只显示 4 个能力 + 3 个状态 + 金钱
- 性格、负向、熟练度**永远不显示数值**，只通过文案与事件体现
- 玩家想深挖时才展开二级页

## 1. 八层结构

| 层 | 名称 | 是否显示数值 | 变化速度 |
| --- | --- | --- | --- |
| L0 | 固有属性 | ✅ 显示 | 极慢（月/年） |
| L1 | 能力属性 | ✅ 显示 | 慢（训练） |
| L2 | 状态 | ✅ 显示 | 快（每天） |
| L3 | 隐藏心理 | ❌ 只给文案暗示 | 中（事件） |
| L4 | 熟练度 | ❌ 隐藏 | 慢 |
| L5 | 粉丝与相性 | ✅ 显示构成 | 中（演出） |
| L6 | 物品与装备 | ✅ 显示 | 随时 |
| L7 | 经济 | ✅ 显示 | 随时 |

## 2. L0 固有属性（有数值，描述式显示）

| 属性 | 变化来源 | 影响 |
| --- | --- | --- |
| 身高 | 年龄、极少事件 | 外观、舞台气场 |
| 体重 | 饮食、训练 | 外观、体力上限 |
| 样貌 | 天生 + 保养 | 第一印象、相性 |
| 身材比例 | 训练、天生 | 舞台表现 |

> L0 **有真实数值，只是显示为描述**（「高挑」「纤细」「清秀」）——玩家看到文字，系统算数字。

四条关键设定：

1. **稀有途径可以改变。** 少数道具 / 事件能永久提升 L0，属于「值得炫耀的成长」，不能靠日常训练刷。
2. **多周目的基础。** 每周目重新 roll 一组 L0，决定「这一局我拿到什么牌」——这是重开的核心动机，不是纯重置。
3. **未来可抽卡化。** L0 天然适合做成「角色抽取」的基础值；现在先留接口与数据结构，不做付费。
4. **需要可序列化 + 可随机生成 + 可继承**，见 [11 数据模型](11-数据模型与存档.md)。

## 3. L1 能力属性（主动成长）

| 属性 | 代码名 | 作用 | 范围 |
| --- | --- | --- | --- |
| 演唱 | `vocal` | 演出主评分、录音类通告 | 0–100 |
| 舞蹈 | `dance` | 演出主评分、舞台类通告 | 0–100 |
| 演技 | `acting` | 影视通告、情绪表达 | 0–100 |
| 口才 | `talk` | 综艺、直播、危机应对 | 0–100 |

成长：递减曲线（前期快、后期慢），单次训练 +1~3。

## 4. L2 状态（短期波动）

| 状态 | 代码名 | 范围 | 归零后果 |
| --- | --- | --- | --- |
| 体力 | `stamina` | 0–100 | 无法行动，强制休息 |
| 心情 | `mood` | 0–100 | 收益系数下降，易触发负向事件 |
| 饱腹 | `satiety` | 0–100 | 体力恢复变慢，久了掉样貌 |

- 饱腹是新增项：把「吃饭」变成每日成本，强化生存期压力
- 心情与饱腹都会影响成长效率，但不是硬门槛（不卡死玩家）

## 5. L3 隐藏心理

### 5.1 性格（6 项，决定事件选项与结局倾向）

| 性格 | 影响 |
| --- | --- |
| 体贴 | 同伴事件、粉丝互动 |
| 领导 | 组合内话语权、带队事件 |
| 合作 | 组团演出加成 |
| 独立 | 单飞事件、拒绝选项 |
| 好强 | 高风险高回报事件 |
| 热情 | 舞台表现、粉丝相性（现场类） |

- 玩家看不到数值，但**选项本身会体现**（性格高 → 解锁对应选项）
- 变化来源：玩家在事件中的选择

### 5.2 负向属性（5 项，触发负面事件）

| 负向 | 触发 | 后果 |
| --- | --- | --- |
| 精神（压力） | 高强度工作、负面舆论 | 全属性下降 |
| 焦躁 | 连续失败、等待 | 主动事件变差 |
| 积劳 | 长期不休息 | 受伤、演出失常 |
| 情欲 | 特定事件 | 绯闻风险 |
| 黑历史 | 错误选择积累 | 结局分支锁定 |

> 负向值是**慢性毒药**：数值不显示，但会在战报与事件里露出（「你最近总走神」）。

## 6. L4 熟练度（隐藏）

| 熟练度 | 影响 |
| --- | --- |
| 舞台场所 | 同一场地演出，稳定性提升 |
| 歌曲 | 同一首歌，评分上限提升 |
| 舞蹈 | 同类型编舞，失误率下降 |

熟练度是**乘区**，不是加区——它放大已有能力，不替代训练。

## 7. L5 粉丝与相性

### 7.1 粉丝类型（6 类）

| 类型 | 喜欢看什么 | 对应偶像特质 |
| --- | --- | --- |
| 舞台 | 现场表现力 | 舞蹈、气场 |
| 噶比 | 可爱、亲密 | 样貌、体贴 |
| 音乐 | 唱功、作品 | 演唱、独立 |
| 现场 | 打 call、应援气氛 | 舞台表现、热情 |
| 养成 | 成长过程、陪伴 | 全属性成长曲线 |
| 慕强 | 实力、成绩 | 演唱 / 舞蹈高分 |

### 7.2 相性怎么算

```
相性系数 = Σ(偶像特质匹配度 × 该类型权重)
粉丝增长 = 演出表现 × 相性系数 × 曝光
```

- 偶像特质来自 L0–L3（样貌、能力、性格）
- 演出内容（曲风、服装、场地）决定**哪类粉丝转化最多**
- 结果是**粉丝构成**变化，不是单一总数

> 这是本作最深的系统：服装风格（古风/Lolita/JK…）不只是外观，它是**粉丝转化的开关**。古风拉「现场」、Lolita 拉「噶比」、摇滚拉「慕强」。

## 8. L6 物品与装备

### 8.1 装备位（7 槽）

| 槽位 | 内容 | 作用 |
| --- | --- | --- |
| 服装 | 古风、打歌服、Lolita、JK、病娇、摇滚、地雷系、妹系、性感、成熟 | 相性转向、外观评分 |
| 发型 | 待补充 | 外观、相性微调 |
| 妆容 | 待补充 | 外观、特定场合 |
| 饰品 ×4 | 待补充 | 属性加成、事件判定 |

### 8.2 道具（6 类）

| 类别 | 例子 | 作用 |
| --- | --- | --- |
| 药物 | 提神药、护嗓含片 | 临时提升属性 / 恢复状态（有副作用） |
| 门票 | 演出票、活动券 | 参与特定活动 |
| 信物 | 粉丝礼物、纪念品 | 提升对应粉丝相性 |
| 食物 | 便当、营养剂 | 恢复饱腹、提升状态 |
| 娱乐道具 | 游戏机、漫画 | 有次数限制，改变心情 |
| 其他 | — | 事件道具 |

### 8.3 装备词条（2026-10-29）

每件装备最多 4 类词条，互不重复：

| 词条类型 | 作用 | 数值范围（普通 / 稀有 / 传说） | 是否显示 |
| --- | --- | --- | --- |
| **成长属性** | 演唱 / 舞蹈 / 演技 / 口才 +N | +1 / +2 / +3 | 显示 |
| **粉丝相性** | 某类粉丝相性 +X% | +5% / +10% / +15% | 显示 |
| **特殊词条** | 条件触发（如「首次登台 +10%」） | 稀有以上才有 | 显示 |
| **熟练度** | 歌曲 / 舞蹈 / 场所熟练度 +N | +1 / +2 | **隐藏** |

稀有度决定词条数：

| 稀有度 | 词条数 | 说明 |
| --- | --- | --- |
| 普通 | 1 | 只有成长属性或相性 |
| 稀有 | 2 | 可带 1 条特殊词条 |
| 传说 | 3–4 | 必带特殊词条 + 熟练度 |

三条平衡规则：

1. **上限锁**：全身成长属性加成，单项合计 ≤ **+20**，防止装备碾压训练。
2. **风格定方向，词条定强度**：服装的 10 种风格决定「吸引哪类粉丝」，词条只决定「强多少」——两者不重复计算。
3. **一件装备最多 1 条熟练度词条**，且永不显示数值。

**隐藏熟练度的处理（重要）**：熟练度数值隐藏，玩家就没法比较两件装备。解法是——

> **隐藏数值，不隐藏有无。** 装备详情显示「手感：略顺 / 很顺 / 极顺」这种定性描述：玩家知道值不值，但算不出精确收益。

## 9. L7 经济

| 项 | 说明 |
| --- | --- |
| 金钱 | 唯一货币 |
| 收入 | 通告、演出、粉丝打赏、赞助 |
| 支出 | 房租、吃饭、训练、装备、道具、占卜 |
| 负债 | 【待确认】是否允许为负 |

### 9.1 装备获取渠道（2026-10-29）

| 渠道 | 稀有度 | 特点 | 设计目的 |
| --- | --- | --- | --- |
| **商店（主）** | 普通 / 稀有 | 花钱买，随时可得 | 金钱的主要出口 |
| **事件（辅）** | 稀有 / 特殊 | 一次性、不可复制 | 回报「做了特别的选择」 |
| **演出 / 通告（稀有）** | 传说 | 低概率或首次必得 | 让「接活」有长期价值 |

三条约束：

1. **商店必须持续进货**：装备是金钱的主要出口，否则后期钱无处可花，经济循环断掉。
2. **演出掉落要防刷**：同一场演出、同一件装备，**首次必得、之后不再出**（或每周限 1 件）。
3. **事件装备不可复制**：给的是「这一局独有的记忆」，多周目才可能再遇到。

> 三条渠道互不重叠：**钱能解决的走商店，选择换来的走事件，努力换来的走演出。**

### 9.2 商店刷新规则（2026-10-29）

| 项 | 规则 |
| --- | --- |
| 刷新单位 | **游戏内周**（不是现实周） |
| 每次刷新 | 重置货架：普通 3–5 件 + 随机 1 件稀有 |
| 解锁 | 每进入新阶段，货架增加新品类 |
| 限购 | 每件限购 **1–2 件**，防止囤货套利 |

> 刷新跟着**游戏时间**走，不跟现实时间走——因为本作的时间由排程推进，用现实周会和游戏进度脱节（见 [12](12-番茄钟与时间系统.md)）。
>
> 快进多周确实会多刷几次货架，但瓶颈是**钱**不是货，所以不会崩经济。

## 10. 演出评分（公式草案）

```
基础分 = 演唱×w1 + 舞蹈×w2 + 演技×w3 + 口才×w4   （权重按演出定位）
最终分 = 基础分 × 熟练度系数 × 装备加成 × 状态系数 × 随机浮动
```

- 定位决定权重：主唱偏演唱，舞担偏舞蹈
- 状态系数：心情 × 饱腹 × 体力
- 随机浮动来自种子（联机时两端一致）

## 11. 呈现原则

| 界面 | 显示什么 |
| --- | --- |
| 主界面 | 4 能力 + 3 状态 + 金钱 |
| 角色页 | 固有属性（描述式）、装备 |
| 粉丝页 | 6 类粉丝构成、相性倾向 |
| 隐藏 | 性格、负向、熟练度——只通过战报文案露出 |

## 12. 实现分期（重要）

这套系统**不可能一次做完**，按下面顺序上：

| 期 | 做哪些 | 理由 |
| --- | --- | --- |
| P0 原型 | 4 能力 + 体力 + 金钱 | 先跑通循环 |
| P1 | 心情、饱腹、服装 1 槽 | 让生存期有压力 |
| P2 | 粉丝 6 类型 + 相性、熟练度 | 演出开始有深度 |
| P3 | 性格 6、负向 5、饰品/妆容 | 结局与事件驱动 |
