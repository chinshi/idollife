## 本文回答什么

- 六类粉丝各自为什么喜欢你、又为什么走？
- 粉丝怎么涨、怎么掉、怎么转化成收入？
- 舆论是什么、怎么影响机会和结局？

## 0. 定位

**粉丝是「他人」轴的发动机。** 三轴里的「他人」= 粉丝情况 + 舆论 + 相关事件，本文负责前两项。

## 1. 六类粉丝

| 类型 | 喜欢什么 | 主要来源 | 最怕什么 |
| --- | --- | --- | --- |
| **舞台** | 现场表现力 | 街演、漫展舞台、拼盘 | 划水、假唱 |
| **噶比** | 可爱、亲密感 | 女仆咖啡、直播、特典 | 高冷、长时间消失 |
| **音乐** | 唱功、作品 | 唱 K、歌唱指导、录音 | 走音、假唱 |
| **现场** | 打 call、应援、现场气氛 | 有互动的演出 | 冷场、没互动的纯唱 |
| **养成** | 成长过程、陪伴 | 持续活动、日记、日常 | 停滞不前 |
| **慕强** | 实力、成绩 | 比赛、OM 舞台、大场 | 掉队、被后辈超越 |

> 每一类都有「喜欢」和「最怕」——这是涨粉与掉粉的两面。

## 2. 粉丝的三个维度

| 维度 | 含义 | 是否显示 |
| --- | --- | --- |
| **数量** | 总粉丝数 | ✅ 数字 |
| **结构** | 6 类占比 | ✅ 等级（强/中/弱） |
| **忠诚度** | 路转粉的深度 | ✅ 分层 |

### 2.1 粉丝分层（2026-10-31 定稿）

| 层 | 含义 | 数量 | 消费力 | 稳定性 |
| --- | --- | --- | --- | --- |
| **单推** | 只推她一个，别的不看 | 少 | **最高** | 最高，但翻车时也最伤 |
| **团推** | 推整个组合 | 中 | 中 | 高 |
| **DD** | 谁都喜欢，谁的演出都去 | 多 | 低 | **低**，容易被别家吸走 |
| **略有兴趣** | 路过看一眼 | 最多 | 极低 | 极低 |

三条推论：

1. **数量看「略有兴趣」，收入看「单推」。** 十万路人不如一百个单推。
2. **DD 是双刃剑**：涨得快、掉得快，是最不稳定的基本盘。
3. **团推随组合规模变化**：组合人越多，团推越重要，单推占比会被稀释。

> 所以「扩组合」和「养单推」是一对天然矛盾——这是本作很核心的取舍。

### 2.2 怎么向上转化（2026-10-31）

**规则：做符合某一类粉丝「喜欢的行为」，该类型粉丝更容易向上转化。**

```
略有兴趣 → DD → 团推 → 单推
```

实现方式：每类粉丝有一个隐藏的**好感值**。

| 事件 | 好感值 | 结果 |
| --- | --- | --- |
| 做该类型喜欢的行为 | +X | 累积到门槛 → 按比例向上转化 |
| 做该类型「最怕」的事 | −Y | 回到下层，或直接流失 |
| 长期无相关行为 | 缓慢衰减 | 向下掉层 |

行为 → 粉丝类型对照：

| 行为 | 推动哪类粉丝 |
| --- | --- |
| 街演 / 漫展舞台 | 舞台 |
| 特典 / 拍切 / 女仆咖啡 / 直播 | 噶比 |
| 唱 K / 歌唱指导 / 录音 | 音乐 |
| 写真 / 造型 / 社媒 | 舞台 |
| 日常更新 / 连续活动 | 养成 |
| 拼盘 / OM 舞台 / 有应援的场 | 现场 |
| 比赛 / 大场 | 慕强 |

两条关键设计：

1. **行为是互斥的。** 一天只有 2 个行动位，去练唱功就没空做特典——**粉丝构成是你选择的结果，不是自然长出来的**。
2. **转化不可逆地偏向一方。** 讨好「舞台」和讨好「噶比」是两种人格，长期只能偏一头。

## 3. 怎么涨

```
涨粉 = 表现分 × 相性系数 × 曝光
```

| 来源 | 涨哪类 | 说明 |
| --- | --- | --- |
| 街演 | 舞台（少） | 路人为主 |
| 漫展舞台 | 舞台 | 有曝光加成 |
| 拼盘演出 | 舞台 + 慕强 | 同行对比 |
| 商演 | 慕强 + 现场 | 钱多，粉质一般 |
| 特典 / 拍切 | 噶比 + 养成 | 亲密度转化 |
| 直播 | 噶比 | 数量快，质量低 |
| 女仆咖啡打工 | 噶比 | 小量 |
| 拍抖音 | 养成 + 噶比 | 看内容 |

## 4. 怎么掉

| 原因 | 掉哪类 | 强度 |
| --- | --- | --- |
| 长期无演出（每 2 周） | 全线小幅 | 缓慢 |
| 翻车 / 负面事件 | 按事件类型 | 剧烈 |
| 内容转型（换风格） | 原类型流失 | 一次性 |
| 假唱 / 划水被揭 | 舞台 + 慕强 | 剧烈 |
| 长时间消失（>1 个月） | 养成 | 剧烈 |

## 5. 粉丝怎么变钱

| 渠道 | 公式 |
| --- | --- |
| 特典 / 拍切 | 核心粉 × 客单价 |
| 商演 | 总粉丝 × 曝光系数 |
| 直播 | 噶比粉 × 打赏率 |
| 赞助 | 核心粉 × 忠诚度 |

> 所以「刷数量」不等于「赚钱」——**核心粉才是钱**。

## 6. 舆论

舆论是「他人」轴的另一半：不是多少人喜欢你，而是**外面的人怎么说你**。

| 状态 | 含义 | 影响 |
| --- | --- | --- |
| **好评** | 业内认可、路人友善 | 好机会出现率↑、收入系数↑ |
| **平淡** | 没人特别在意 | 基准 |
| **争议** | 有话题但有风险 | 曝光↑、好机会↓、负面事件概率↑ |
| **翻车** | 公开负面 | 机会关闭、粉丝流失、可能触发中断结局 |

- 舆论**不显示数值**，通过事件、社媒动态、评价事件体现
- 「争议」是最有意思的状态：**有热度但危险**
