## 1. core：颜值（样貌）数值 → 区间文案

`packages/core/src/attributes.ts` 新增导出（放这里，不要新建文件）：

```ts
export function appearanceLabel(v: number): string
```

区间（文案由策划定，**照抄，不要自己发挥**）：

| 数值区间 | 文案 |
| --- | --- |
| 0–19 | 不上镜 |
| 20–39 | 普通 |
| 40–59 | 耐看 |
| 60–79 | 上镜 |
| 80–89 | 很上镜 |
| 90–100 | 镜头会追着你 |

边界与容错：`v < 0` 按 0–19 档；`v > 100` 按 90–100 档；非数字/NaN/undefined → `'—'`。取整用 `Math.floor`。

测试（新增用例，挂在现有 core 测试文件或新建 `attributes-appearance.test.ts`）：6 档各一条精确断言 + 边界值 19/20/39/40/89/90 + 越界 −5 与 120。

## 2. 属性面板按数据标志显示，删掉硬编码打码

`StatsPanel.tsx` 第 4 行有个硬编码集合：

```ts
const HIDDEN_CATEGORIES = new Set(['trait', 'negative', 'hidden', 'proficient']);
```

它把 性格/负向 的值显示成「？」——**已经和配置表冲突**（用户这次把 性格/负向 改成显性了）。删掉它，改成读数据标志：

- `linked === 0`（目前只有熟练度三项）→ **整组不渲染**；
- 其余全部渲染真实数值；
- `linked === 2`（性格 / 负向 / 三轴）→ 分组标题后跟一个灰色小标「仅占卜可见」，**数值照常显示**（这是玩家自己的档案页，藏数字只会让人骂）；
- `hidden === true`（固有 / 状态 / 三轴 / 粉丝）→ 分组标题后跟灰色小标「主界面不显示」，**数值照常显示**。

### 分组顺序（显式写死，不要依赖数据里的行序）

`成长属性(visible)` → `状态(status)` → `固有属性(innate)` → `性格(trait)` → `负向(negative)` → `三轴(hidden)` → `资源`

分类名和属性名都从 `ATTRIBUTES` 取（`a.categoryName` / `a.name` / `a.key`），不要写死中文。

## 3. 样式（策划定调，按这个做）

| 分组 | 呈现 |
| --- | --- |
| 成长属性（演唱/舞蹈/演技/口才） | 名称 + 数字 + 横向条（条宽 = 值/100）。四行，视觉权重最高 |
| 状态（体力/心情/饱腹） | 同上加 `/100` 后缀。语义色：`< 30` 橙、`< 15` 红，正常中性色 |
| 固有属性 | 身高 / 体重 / 身材比例 显示数字；**样貌只显示 `appearanceLabel(值)` 文案，任何地方都不出现样貌的数字** |
| 性格（6 项） | 细条 + 数字，中性色 |
| 负向（5 项） | 细条 + 数字，用偏冷的暗色区分（不要和状态警示色混） |
| 三轴（自我/他人/适配） | 细条 + 数字，标题带「仅占卜可见」 |
| 资源 | 资金 `¥8,620`（千分位）、粉丝总数（千分位） |

- 底部那行「实际属性」现在输出的是英文键（`vocal 22`），**改成中文**：`实际属性：演唱 22 · 舞蹈 30 · 演技 12 · 口才 11`（用 `STAT_LABEL`）。
- 样式写在 `packages/client/src/styles.css`，复用现有 `.attr-*` 类，新增 `.attr-bar` / `.attr-radar` 等；**不引入任何新的依赖或图表库**。
- 窄屏不溢出：条形用百分比宽度，不要固定 px。

## 4. 粉丝构成：六维图（雷达图）

新增 `packages/client/src/components/FanRadar.tsx`，**纯 SVG 手写**，不要装三方图表库。

- 六轴，轴名与顺序取自 core 的 `FAN_KEYS` / `FAN_LABEL`（舞台粉 / 嘎起粉 / 音乐粉 / 现场粉 / 养成粉 / 实力粉），**不要写死**。数值用 `attrValue(run, key)`。
- 归一化：半径按「六类里的最大值」为满圆（`r = v / maxv`）。`maxv === 0`（还没粉丝）时**不画图**，显示空态文案「还没有粉丝构成」。
- viewBox `0 0 200 200`，3 圈网格 + 轴线 + 半透明填充多边形；轴标签文字 10–11px，旁边带数值（如「舞台粉 120」）。
- 在属性面板里：**「成长属性」分区下方整行居中**，标题「粉丝构成」，容器 `width: 100%; max-width: 240px`（别把面板撑宽）。
- 六个轴的中文名较长，标签要避让溢出（左/右两侧标签分别用 `text-anchor: end / start`，上下用 `middle`）。
