## B. 手动停止没有被持久化，刷新后自动恢复执行

### 根因（已核实）

`App.tsx` 第 1426 行：

```ts
// 刷新后：如果还有待执行行程，自动续跑（离线设计，读档即继续）
const bootResumeRef = useRef(false);
useEffect(() => {
  if (bootResumeRef.current) return;
  if (!user) return;
  if (!schedule.some((s) => !s.done)) return;
  bootResumeRef.current = true;
  const t = window.setTimeout(() => advanceRef.current(), 400);
  ...
}, [user, schedule]);
```

`doStop()`（第 1154 行附近）只做了 `setRunning(false)` + 重置锚点，**没有记录「玩家主动暂停」这个事实**。刷新后该 effect 看到仍有未完成行程 → 直接 `advance()`，于是**恢复执行**。

用户判断正确：就是没记录时间流逝的暂停状态。

### 要求

1. **持久化暂停标记**：`doStop()` 里写入暂停状态。建议直接扩展已有的时钟记录：

```ts
localStorage.setItem('idollife:clock:v2', JSON.stringify({
  t: Math.round(runRef.current.at),
  w: Date.now(),
  speed,
  paused: true,
}));
```

（读旧记录时 `paused` 缺省按 `false` 处理，向后兼容。）

2. **启动时尊重暂停**：bootResume effect 里若 `paused === true` → **不自动 advance**，并给提示「上次手动停止了行程，点「推进」继续」。仍然要置 `bootResumeRef.current = true` 防止重复触发。

3. **恢复执行时清除标记**：`advance()` 成功启动推进时清 `paused`（写回 `paused:false`）；事件处理后的自动续跑路径同样被视为「继续」，一并清掉。`restartForTest()`（重开）必须清空该 key，避免新档继承暂停态。

4. **边界**：因「时间跑完 / 遇事件 / 行程全部完成」自然停下时**不要**设 `paused`（那是正常结算，不是玩家意图暂停）。只有玩家点「停止」并确认（`doStop`）才设。

### 自测（必须给出）

- 有未完成行程 → 点停止 → 刷新 → **不再自动推进**，提示正确，点「推进」后恢复。
- 有未完成行程 → 不点停止 → 刷新 → 仍自动续跑（不能把正常离线推进弄坏）。
- 重开后不继承暂停态。

## C. 安排行程弹窗

**要求**：

- `.action-group-head` 显式加 `flex-direction: row`（三角在名称前、同一行、垂直居中）。

**现状**：`.date-grid` 是 4 列（`repeat(4, …)`）× 2 行，每格 `min-height: 104px` → 整体只有约 220px 高，而弹窗主体高 72vh（约 500px），下面大片空白。`.plan` 又是 `align-items: flex-start`，右侧不拉伸。

**要求**：

- `.date-grid` 改 **2 列**：`grid-template-columns: repeat(2, minmax(0, 1fr))`，`grid-auto-rows: 1fr`，8 个日期 → 4 行。
- 撑满容器：`.plan { align-items: stretch; }`；`.plan-grid-wrap` 改 `display: flex; flex-direction: column; min-height: 0;`，`.date-grid { flex: 1 1 auto; min-height: 0; }`。
- `.date-cell` 高度跟随行高，`min-height` 去掉（或降到 64）；`.date-slots { flex: 1 1 auto; justify-content: space-between; }`，空槽均分剩余高度，不要挤在顶部留白。
- 左侧 `.plan-actions` 同步填满：去掉 `max-height: 470px`，改 `height: 100%; max-height: none;`（内部滚动保留）。

**验收要点**：弹窗打开后右侧 8 个日期框 4 行铺满到底部，不出现「内容只占上半屏」的空洞；分类头一行高、三角在名称左侧。
