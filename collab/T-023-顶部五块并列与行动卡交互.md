## 4. 行动卡：层级标识与名称同行 + 压高度

### 现状与目标

`.action-card` 目前 `display:flex` 但 `min-height: 40px`、`padding: 6px 8px`，名字/层级/摘要挤在同一行容易溢出换行，卡片偏高。

目标：**保证单行，高度压到 30–32px**。

- 结构保持 `[名称] [初/中/高] [摘要（右，可省略）]`
- `.action-card`：`min-height: 30px; padding: 4px 8px; gap: 5px; line-height: 18px;`
- `.action-card-name`：`font-size: 12px; font-weight: 600; white-space: nowrap; flex: 0 0 auto;`
- `.action-tier`：紧跟名称（`flex: 0 0 auto`），`font-size: 10px; line-height: 16px; padding: 0 4px;`
- `.action-card-sum`：`flex: 1 1 auto; min-width: 0;` 保留省略号，`font-size: 10px`
- 名称过长时只允许名称 `text-overflow: ellipsis`（给名字 `max-width` 或 `overflow:hidden`），**不允许换行把 tier 挤到第二行**
- 校验：弹窗内一屏可见的行动卡数量应比现在明显增加（约多 30%）

## 5. 悬浮框：移到行动框左侧且不遮挡

### 现状

`ActionCard.tsx` 的 `openTip` 让悬浮框在卡片**正上方/正下方居中**（`left = r.left + r.width/2 - W/2`），会盖住相邻卡片或行动区域。

### 目标

默认显示在**行动卡左侧**，与卡片之间留 8px，垂直方向尽量与卡片对齐，**任何情况下都不覆盖行动卡本身**。

### 定位算法

```ts
const W = 260;               // tip 宽度（.action-tip 固定 260）
const H = 实际测量高度;       // 先渲染再量，或用 190 兜底；实测更稳
const gap = 8;

// 水平：优先左侧，左侧空间不足则右侧，两侧都不足才回退到上方/下方
const leftSide = r.left - gap - W >= 8;
const rightSide = r.right + gap + W <= window.innerWidth - 8;
let left: number;
let placement: 'left' | 'right' | 'top' | 'bottom';
if (leftSide) { left = r.left - gap - W; placement = 'left'; }
else if (rightSide) { left = r.right + gap; placement = 'right'; }
else { /* 兜底：上方居中，空间不足再下方 */ }

// 垂直：与卡片顶部对齐，clamp 进视口
const top = Math.min(Math.max(8, r.top), window.innerHeight - H - 8);
```

### 箭头

`.action-tip` 现有 `::after` 只支持上下箭头。新增：

- `.action-tip.side-left::after`：箭头贴在**右边缘**（`right: -10px; top: 中间`），指向右侧的卡片
- `.action-tip.side-right::after`：箭头贴在左边缘

箭头垂直位置跟随卡片中心（用 CSS 变量或内联 `top` 传），保证指着卡片而不是卡片外。tip 与卡片之间不留重叠，鼠标从卡片移到 tip 不应中断（沿用现有 140ms 延迟与 `onMouseEnter` 保持逻辑）。

### 验收

- 鼠标悬浮任意行动卡，tip 出现在卡片**左侧**
- tip 的矩形与卡片矩形**无交叠**（可用 getBoundingClientRect 判断，回执附实测说明）
- 卡片贴最左（弹窗左侧列）时，tip 自动翻到右侧
- 视口上下边缘不溢出

## 6. 分类标题：加大、显眼、可折叠、默认展开

### 现状

`Modals.tsx` 弹窗左栏按 `growth / recover / work` 分组，标题是 `<h4>{CATEGORY_LABEL[cat]}</h4>`，样式 `.action-group h4 { font-size: 13px; color: var(--muted) }`——小而灰，几乎看不见。

### 目标

- **样式明显**：分组头做成可点击的横条
  - 字号 15px、`font-weight: 700`、深色（`var(--text)` 或 `#22252b`）
  - 左侧一个小三角指示（展开 `▾` / 收起 `▸`），右侧显示该组行动数量（如「成长 12」）
  - 常态有浅底色（如 `#f5f7fb`）+ 圆角 6px + 上下 6px 内边距，hover 变深一档，`cursor: pointer`
  - 分组之间间距加大到 10–12px
- **可折叠**：点击分组头收起/展开该组全部行动卡（收起时只留标题行）
- **默认展开**：每次**打开**「安排行程」弹窗时，三组都回到展开状态（折叠状态不跨次保留）。实现方式：折叠状态 `useState` 放在弹窗组件内，或打开时用 `useEffect` 依赖 `open` 重置；不要写进持久化
- 折叠状态纯 UI，不影响配置数据；收起时已排入日期框的条目不受影响
