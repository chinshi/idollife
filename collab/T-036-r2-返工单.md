## 1. 必须修的两个真实漏洞

### 1.1 退出登录没重置内存态 → 老档（`ownerId` 缺失）会把老 runId 复活

**现状**：`doSignOut()` 只做了 `clearSave() / resetOutbox() / clearLocalClock() / signOut()`，**React 里的 `runId / run / schedule / revision` 一个没动**；而 `const boot = useRef(loadSave()).current` 是**首帧冻结**的对象，登出后依然指向老档。

**后果**：同一台设备「退出 A → 登录 B」时，若 A 的档是本次改造之前写的（没有 `ownerId`）：
- `resolveBootSave(boot, B)` 命中「老档缺失 ownerId → 原样返回」这条兼容分支 → 不重置；
- `runId` state 仍是 A 的 → `fetchLatestRun` 拿到 B 的档但 `localEmpty` 为假、`latest.revision > baseRevision` 未必成立 → 不采纳；
- B 若云端没有档 → `pushChoice(A 的 runId)` 用 B 的身份占了这个 id。

这正是产品所有者反馈的「换号之后老账号的登录态没去掉」。

**改法**：

1. `const boot = useRef(loadSave()).current` → 改成可写的 `const bootRef = useRef<SaveV2 | null>(loadSave())`，所有用到 `boot` 的地方改读 `bootRef.current`（首帧初始化语义不变）。
2. `doSignOut()` 在 `signOut()` 之前补：
   ```ts
   const fresh = createSave(autoAcceptTasks(normalizeRun(initialRun)), 'run-demo');
   bootRef.current = null;        // 登出后没有任何本地档可继承
   setRunId(fresh.runId);
   commitRun(fresh.run);
   scheduleRef.current = [];
   setSchedule([]);
   setRevision(0);
   setSavedAt(null);
   commitClock(createClock(initialRun.at));
   setRunning(false);
   setReadonlyBanner(false);
   ```
3. `resolveBootSave` 的兼容分支**保持原样**（老档没有 ownerId 时仍可用），隔离靠「登出即清内存 + 清存储」保证。

**一票否决**：只清 storage 不清内存；或把 `resolveBootSave` 改成「缺 ownerId 就丢弃」（会把所有老玩家的本地进度一次清空）。

### 1.2 `onForbidden` 只清缓存就 `retryClockSession()` → 一定再 403，玩家卡死在「云端时钟读取失败」

**现状**：
```ts
onForbidden: () => {
  resetOutbox(runId); clearSave();
  setNotice('这一局属于另一个账号，本地缓存已清空。');
  void retryClockSession();   // ← runId 是指向老 runId 的闭包
}
```
403 的含义是「当前 runId 不属于本账号」，拿同一个 runId 再确认一次必然再 403。

**改法**：403 是终态，直接按「新账号重新开档」走一次干净的启动：

```ts
onForbidden: () => {
  resetOutbox(runId);
  clearSave();
  clearLocalClock(runId);
  bootRef.current = null;
  setNotice('这一局属于另一个账号，正在按当前账号重新同步…');
  window.setTimeout(() => window.location.reload(), 1200);
},
```

- 必须延时（≥1000ms）让 notice 能被看到；不许 `location.reload()` 立刻调。
- 重载后 `bootRef` 为空 → 用新 runId → `fetchLatestRun` 采纳本账号云端档。
- 在 `pulledFor`/boot 逻辑里不要为此新增分支。
