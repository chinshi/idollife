## B. 安排行程弹窗（`packages/client/src/components/Modals.tsx` + `App.tsx` + `styles.css`）

### B0. 先统一「槽位」概念（其余四条都建立在它上面）

一天 = `DAILY_SLOTS`（3）个槽。一个行动占 `ceil(durationMs / ACTION_MS)` 个槽（演出类 3 槽 = 整天）。

新增纯函数（放 `packages/core/src/plan.ts`，从 `packages/core/src/index.ts` 导出；**核心包禁 `Date.now` / `Math.random` / DOM**）：

```ts
export interface SlotPlanInput {
  schedule: ScheduleItem[];  // 含 done / fixed
  at: number;                // 当前游戏时间 run.at
  durationMs: number;        // 待排行动的时长
  dayMs: number;             // DAY_MS
  actionMs: number;          // ACTION_MS
  slotsPerDay: number;       // DAILY_SLOTS
  maxDays?: number;          // 默认 60
}
/** 返回落位；filled=true 表示补了中间空位，false 表示追加到末尾 */
export function placeAction(input: SlotPlanInput): { startAt: number; filled: boolean };
```

**落位规则（按顺序，先命中先返回）**：
1. 逐日构建占用表：done 项与 pending 项都算占用；起始槽 = `round((startAt - dayStart) / actionMs)`，夹在 `0..slotsPerDay-1`，`span = ceil(dur/actionMs)`。
2. 从 `at` 所在日开始向后扫，每天内按槽序扫，找**第一段连续 `span` 个空槽（必须同一天内）**，且该槽起始时间 `>= at`。
3. 若候选位置与任何已有项 `[startAt, endAt)` 重叠 → 跳过该候选（保底：旧存档可能槽位不对齐）。
4. 命中 → `startAt = dayStart + slotIndex * actionMs`，`filled = true`。
5. 扫到 `maxDays` 都没命中 → 走旧逻辑追加到末尾（`max(at, 最后一条 endAt)` 起，当天放不下就顺延到次日），`filled = false`。

`App.tsx:1134 addAction` 改为调用它；**插入到中间后必须把 schedule 按 `startAt` 升序重排再 setSchedule**（`pending = schedule.filter(!done)` 依赖数组即时间顺序，`nextStart()` 取 `pend[0]`，不排序会取错下一条）。`scheduleRef` 同步。

### B1. 空槽文案：`空` → `动作1 / 动作2 / 动作3`

- 文案按**槽位序号 +1**，不是按剩余空槽数。今天已执行 2 条 → 剩下那一格显示「动作3」。
- 空槽保持虚线灰底，字号沿用 11px。

### B2. 当天已执行的行动：写进对应格、置灰、不可删

- 数据源：`schedule` 里 `done === true` 且 `floor((startAt - T0)/DAY_MS) === 当前日` 的项。
- 显示在**它真实的槽位**上（按 `startAt` 排序），灰底灰字 + 「已完成」小标，**不渲染 ⊗**。
- 正在执行的那条（未 done 且 `startAt <= run.at`）也要显示在该槽上，标「执行中」，同样不可删（现在它挂在待执行里可删，会把进行中的行动删掉）。
- 网格**从今天开始**，不再从「第一个还有空位的日子」开始（现在 `Modals.tsx:196-204` 的 `startDay` 逻辑会跳过今天，导致今天的已执行项看不到）。

### 3. placeAction 实现要点

- **占槽表**：把 `schedule`（done + pending）逐个按 `floor((startAt-START_AT)/dayMs)` 归日；槽序 `clamp(round((startAt-dayStart)/actionMs), 0, slotsPerDay-1)`，span=`ceil(dur/actionMs)`，标记连续槽占用。

- **重叠判定**：除了槽表，还用真实区间 `[startAt,endAt)` 与候选 `[candidate,candidate+duration)` 做一次 overlap 检查（兜住旧存档 startAt 不对齐的情况），命中即跳过。
