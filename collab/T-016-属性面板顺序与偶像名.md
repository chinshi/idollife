## 1. 偶像名（新增）

### 1.1 数据

- `packages/core/src/types.ts`：`RunState` 增加 `name?: string`，注释写「偶像名；老档缺省，缺省时在界面上按『未命名』处理」
- **不需要存档迁移**：字段可选，读档缺省就是未起名。存档版本仍为 2，别动
- `packages/client/src/App.tsx`：`initialRun` 里不要写死名字（留空 = 未起名）
- `packages/client/src/state/save.ts`：在字段校验里补 `name`——是字符串且 trim 后非空就保留，否则为 undefined。**不补的话读档会丢名字**

### 1.2 开局起名

进入游戏后，若当前 run 的 `name` 为空（新档：本地无存档且云端无存档），弹起名对话框：

- 一个输入框 + 两个按钮：「开始」（保存）/「跳过」（用默认名 `未命名`）
- 复用现有模态框写法（`Modals.tsx` 或 App 内的 modal 实现），**不要新引三方库**
- 名字规则：`trim`，长度 1–12 字符；为空等同于跳过
- 起名成功后**立即写一次存档**，否则刷新页面会再弹一次
- 已经起过名的档（本地或云端有 name）不再弹

### 1.3 面板顶部显示

属性面板最顶部（`<div className="mod-head">` 那块附近）显示偶像名：

- 单独一行，字重/字号比分组标题更高一号，新增 class（如 `.attr-idol-name`）
- 未起名时显示 `未命名`（样式弱一点，提示可点）
- **点击可修改**：复用同一个输入入口；改完立即存档
- 样式你自己定，跟现有面板风格一致即可（参考 `styles.css` 里 `.mod-head` / `.attr-group h4` 的写法）

## 2. 分组顺序

`StatsPanel.tsx` 的 `GROUP_ORDER` 改为：

```
['innate', 'status', 'visible', 'trait', 'negative', 'hidden']
```

即：**固有属性 → 状态 → 成长属性 → 性格 → 负向 → 隐藏属性**

- 粉丝构成（雷达图 `FanRadar`）紧跟在**成长属性之后**渲染（原来是跟在成长属性后，位置不变）
- 「资源」section 保持在最后
- `linked === 0` 的组（熟练度）仍然整组不渲染，这条别丢

## 3. 显示名：「成长属性」

配置表里 `visible` 组的 `categoryName` 是「显性属性」，用户要叫「成长属性」。

- 在 `StatsPanel.tsx` 里加显示名映射，例如：

  ```ts
  /** 界面叫法与配置表不同：配置表沿用「显性属性」，界面按用户口径叫「成长属性」 */
  const GROUP_DISPLAY_NAME: Record<string, string> = { visible: '成长属性' };
  ```

- **不要改 `content/all.xlsx`，也不要手改 `packages/core/data/attributes.json`**（它是导入产物，改了下次导入会被覆盖）
- 只在渲染分组标题时套用这个映射，其它地方不动

## 4. 状态组：三项全部进度条

`status` 组的三项（体力 / 心情 / 饱腹）**统一渲染成进度条**，视觉一致，不能有哪一项退化成纯数字：

- 每行：名称 + `数值/上限` + 一条进度条
- 上限：体力用 `STAMINA_MAX`，心情 / 饱腹 用 100
- 色调规则三项都适用（现在只对体力生效的部分要扩到心情/饱腹）：`< 15` 危险红、`< 30` 警告橙、其余常态
- 条型与其它组的条保持一致，不要另起一套样式

---

## 5. 其它组：维持现状（别顺手改）

- **固有属性**：纯文字，不加条。样貌走 `appearanceLabel()` 只出文案（不上镜 / 耐看 / …），**不显示数字**；身高 / 体重 / 身材比例显示数值，也不加条
