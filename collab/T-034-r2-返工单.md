## P0 必须改：把曲线改成「截止前 2 天填满」

你自己在回执里指出的那条是对的：按我给的曲线，`d > 7` 时因为 `min(n-1, …)` 保护，
**空位永远 ≥ 1**，所以 `已满` 徽标在真实数据里不可达。这是我这单的设计漏洞，现在改曲线。

### 新曲线（替换 §2.1 全表）

| d | 填充比例 |
|---|---|
| d > 14 | 0 |
| 14 | 0.05 |
| 13 | 0.15 |
| 12 | 0.28 |
| 11 | 0.45 |
| 10 | 0.65 |
| **9** | **1** |
| 8 | 1 |
| d ≤ 7 | 1（但 `cardState` 走 announced，标签显示「已宣发」） |

- 即：**距截止 2 天（d=9、8）开始出现「已满」**，d≥10 时仍然保证至少 1 个空位
- `min(n-1, …)` 保护**保留不变**（它只在 `ratio < 1` 时起作用，正是它保证 d≥10 有空位）
- 实测参考（改后）：

| d | n=4 | n=1 | n=18 |
|---|---|---|---|
| 15 | 0 | 0 | 0 |
| 14 | 0 | 0 | 1 |
| 13 | 1 | 0 | 3 |
| 12 | 1 | 0 | 5 |
| 11 | 2 | 0 | 8 |
| 10 | 3（留 1） | 0 | 12 |
| 9 | **4（满）** | **1（满）** | **18（满）** |
| 8 | 4 | 1 | 18 |
| 7 | 4（已宣发） | 1 | 18 |

### 必须补的用例（core）

1. `npcFillRatio`：`d=10 → 0.65`、`d=9 → 1`、`d=8 → 1`；`d=15 → 0` 保持不变
2. **可达性（这条是产品要求，不许删）**：
   ```ts
   // 一线某场 4 顺位，d=8 时 cardState 必须是 full（不是 open、不是 announced）
   const occ = scheduleWeek(1, 3, 'seed-abc').find((o) => o.slots.length >= 4)!;
   const npc = npcOccupied(occ, occ.startAt - 8 * DAY, []);
   expect(cardState(occ, occ.startAt - 8 * DAY, npc)).toBe('full');
   ```
   （`cardState` 在 `packages/client/src/components/show-card.ts`；如果 core 侧不便引入，
   就在 client 的 `tests/show-card.test.ts` 里写这条，并同时在 core 侧断言 `npcOccupied` 的 size === n）
3. 单顺位：`d=10` 占 0、`d=9` 占 1
4. 更新 r1 里这两条受影响用例（d=10 由「留 1」变成 3 占位的断言要跟着改）

## P1 四处必修

### 1. 名气 / 粉丝未达标没标红

弹窗里只有四项属性用了 `req-bad`，`名气 {s.reqFame}` 和 `粉丝 {s.reqFans}` 无论够不够都是黑字。
截图里玩家名气明显不足，`名气 450` 仍是黑色 —— 这与「未达标的用红色文字表示」直接冲突。

- 名气：`chk.missing.fame !== undefined` 时整段红
- 粉丝：`rowChk.missing.fans !== undefined` 时红
- 顺带把 `bad()` 里冗余的 `!rowChk.ok &&` 去掉（属性未达标本身就够判红，不需要再看整体）
- 成员数（`reqParty`）不足时同样标红

### 2. 报名成功后弹窗既不关、文案还错

`bookShow(occ, slot)` 成功后 `run` 变了，弹窗重算后 `selectedTaken` 为真，按钮显示 **「位置已被占」** ——
但那个位置是**玩家自己刚占的**，玩家会以为报名失败了。

- 文案分支改：`mineSlots.includes(slot.slot)` 优先于 `npc.has(...)`，显示 **「你已报名」**
- 报名成功后**自动关闭弹窗**（`onClose()`），让玩家回到列表看到卡片变成「已报名」

### 3. 金额格式不一致

弹窗顺位行用 `¥1,000`（有千分位），底部操作条用 `¥1400`（无）。统一走千分位。

### 4. 死代码清理

- `statusWeight(state, mineCount, d)` 第三个参数 `d` 完全没用到（函数体里 `void d;`）→ 删掉参数和调用处的实参
- `styles.css` 里 `.show-lineup` / `.show-slot` / `.show-slot.active` / `.show-slot.taken` / `.show-req` / `.show-fee`
  已无任何引用（卡面删掉顺位块与要求平铺后）→ 删除
- 卡片上「已报名」徽标目前复用 `.status-announced`（橙色「已宣发」同款），语义混了 → 新增 `.status-mine`（主色底），单独用
