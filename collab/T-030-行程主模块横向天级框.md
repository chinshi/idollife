## 二、口径（实现不得偏离）

1. **横向滚动的一列天框**，每格 = 一天 = `DAILY_SLOTS`(3) 个竖排槽位，格宽约 96px 固定，格数由数据决定，超出横向滚动。
2. **天数范围**：`fromDay = 0`（第 1 天）→ `toDay = max(currentDay, 所有排程项所在的最大天)`。
   - 中间没有排程的空白天**必须渲染**（否则滚动会跳、天数不连续）。
   - 末尾**追加**一格「＋ 点击安排行程」，点击调 `openPlan()`。
3. **初始滚动位置**：mount 时把 `dayIndex = max(0, currentDay - 2)` 那一格的左边缘对齐容器左边缘。
   - 只有 **mount 时定位一次**。`currentDay` 随推进变化时**不得**重置滚动（否则玩家正在看的位置会被拽走）。
   - 组件在切 tab 时会 unmount/remount，天然满足「每次打开本模块都回到前天」。
4. **三态视觉区分**（用户要求）：
   - `past`（`day < currentDay`）：灰底 `#f7f8fa`、整体 `opacity: .75`、边框更淡；头部加一个「已过」小标；该天若全部 done 再标 ✓。
   - `today`（`day === currentDay`）：边框换成强调色（`var(--accent)`）、浅强调底、头部显示「今天」徽标。
   - `future`（`day > currentDay`）：白底正常。
5. **空槽文案**：`past` 天显示「空」（淡灰）；`today` / `future` 天显示「动作N」（沿用弹窗的补位提示）。
6. **已执行项**：灰显 + 勾，不可点、不可删（主模块只读）；分类配色沿用 `.date-slot.cat-*`。
7. **正在执行的那一项**：高亮描边 + 「执行中」标记（比弹窗更明显一点，主模块是玩家盯着看的地方）。
8. **滚轮**：鼠标纵向滚轮在该容器内转成横向滚动（`deltaX` 优先，`deltaY` 转 `scrollLeft`），仅当容器可横向滚动时生效。
9. 标题区保留 `<h2>行程</h2>` + 「待执行 N 个」，右侧保留一个「安排行程」文字按钮（与末尾加号格同入口）。

## 三、抽公共函数（重要，避免两处槽位算法漂移）

现在槽位计算在 `Modals.tsx:250-300` 里是手写的 inline 逻辑。主模块要再抄一遍就会有两份，以后改一处忘另一处。

**抽到 `packages/core/src/plan.ts`**（纯函数，禁随机/时间/DOM）：

```ts
export interface DaySlot { item: ScheduleItem | null; covered: boolean; index: number }
/** 把某一天的排程按 ACTION_MS 落成 slots 个槽位；跨槽项（演出占 3 槽）用 covered 标记被占位 */
export function buildDaySlots(
  items: ScheduleItem[],
  dayStart: number,
  slots: number,
  actionMs: number,
  spanOf: (item: ScheduleItem) => number,
): DaySlot[]
```

`spanOf` 仍留在调用方（演出时长来自 content）。弹窗与主模块**都改成调用它**。

必须新增 core 用例（`packages/core/tests/plan.test.ts`）：
1. 空天 → `slots.length === 3`，全部 `item: null`、`covered: false`
2. 一条跨 3 槽的项 → `slots[0].item` 有值，`slots[1]/[2].covered === true` 且 `item === null`
3. 两条同起点重叠 → 后者被丢弃（现有行为：`if (slots[idx]) continue;`）——把这条行为写成断言，防止将来改成覆盖

### 2. 初始滚动定位 / currentDay 变化不重置

- **实现方式**：mount 后 `useEffect(..., [])` 里取 `scrollRef`，`idx = max(0, currentDay-2)`，用 `querySelector('[data-day="idx"]')` 找天框，按 `target.getBoundingClientRect().left - container.getBoundingClientRect().left` 加到 `scrollLeft`，等价于把「前天」左边缘对齐容器左边缘（不是 `scrollIntoView`，避免纵向跳动）。
- **不重置**：定位 effect 的依赖数组为空且只在 mount 跑一次；`days` / `currentDay` 都在 render 中重新计算，但不会触发该 effect。切 tab 时 `PlanPanel` 卸载/重挂，自然满足「每次打开本模块回到前天」。
- **滚轮**：仅当 `scrollWidth > clientWidth` 时生效，避免纵向页面滚动被劫持。
