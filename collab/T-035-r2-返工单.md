## 1. 问题（策划验收发现，3 条）

### 1.1 【P0】时间轴工具行的控件真实重叠，`8×` 点不到

`.tlx-tools` 是 `grid-template-columns: minmax(0,1fr) auto minmax(0,1fr)`：
中列 `auto` 由「开始推进 / 停止 / 第 N 天 / 安排行程」撑开，左列被压到小于自身内容宽，
而 `.tools-left` 不换行、`.tlx { overflow: hidden }` —— **左列内容溢出到中列下方被覆盖**。

实测截图（`.tmpdev/crop-speed.png`，3 倍放大）：`8×` 的「×」被橙色「推进中…」按钮盖住，
「8」还露着。后果：8 倍速点不到，点「8」的位置会误触「开始推进」。**任何视口宽度下都不允许出现控件互相覆盖。**

### 1.2 【P1】次数文案有歧义

现在产出：`「兼职打工」本局次数已用完（每局 1 次），删掉它后面的行程才能走。`

「删掉它后面的行程」会被读成「删掉排在它后面的那些行程」——正好和本意相反。
改为：`「兼职打工」本局次数已用完（每局 1 次），删掉它，后面的行程才能走。`（加一个逗号）。

`packages/client/tests/advance-block.test.ts` 补一条断言：文案包含 `删掉它，` 这个带逗号的片段。

### 1.3 【P1】横幅会「撒谎」

横幅出现后，玩家点「去安排行程」把那条删掉，横幅仍挂在主区域顶部说「「唱 K」体力差 10，这一条排在队首，推不动」，
而左侧 `PlanPanel` 的紧凑提示已经消失。两处矛盾，且横幅指向一条已经不存在的行程。

## 2. 契约

### 2.1 工具行不重叠

任选其一实现，但必须满足：**所有控件完整可见、可点、不裁字、不互相覆盖**。

- 方案 A（推荐）：`.tlx-tools` 改 `display: flex; flex-wrap: wrap; justify-content: space-between; gap: 8px;`
  三组 `flex: 0 0 auto`，放不下时整组换到第二行。
- 方案 B：拆成两行固定布局 —— 第一行「设置暂停时间点 + 倍速 + 开始推进 + 停止」，
  第二行「第 N 天 · 第 N 周 周X + 安排行程 + 历史行程 + 状态」。

禁止：给 `.tools-left` 加 `overflow:hidden` 或 `text-overflow: ellipsis` 把 `8×` 藏掉；给按钮加负 margin。

验收要看到 `1× 2× 4× 8×` 四个按钮**各自有完整边框**且互相不贴合。

### 2.2 横幅绑定条目，条目消失即失效

- `AdvanceBlock` 增加 `itemId?: string`（拦截时取队首那条的 `id`）。
- `App.tsx` 增加一个 effect：
  ```ts
  useEffect(() => {
    const id = advanceBlock?.itemId;
    if (!id) return;
    if (!schedule.some((s) => s.id === id && !s.done)) setAdvanceBlock(null);
  }, [schedule, advanceBlock?.itemId]);
  ```
- 同时清 `lastStop`（`setLastStop('')`），避免顶栏徽章继续挂着旧原因。

### 2.3 次数文案

`advance-block.ts` 完整版末尾改为 `，删掉它，后面的行程才能走。`（含逗号）。
紧凑版（`compact: true`）不动。
