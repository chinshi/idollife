## 0. 背景与目标

T-032 把演出按「城市 × 顺位」写进了配置表：三线/二线/一线/超一线各有一整套演出，配置量随城市数线性膨胀，加一场演出要写 4 遍。

T-033 反转这个方向：

> **演出不再分城市。演出池只有一份，每场演出自带「顺位数」和「演出级别」。城市只决定「能看到多少场、多大的场、什么类型」。**

同时给演出加**演出级别**（普通 / 大型拼盘 / 中外拼盘 / 节日SP / 生日SP / 毕业SP / 出道SP），级别既表达规模，也用作城市过滤的一维。

新增导出：

```ts
export type ShowTier = 'normal' | 'large' | 'sino' | 'festival' | 'birthday' | 'graduate' | 'debut';
export const TIER_LABEL: Record<ShowTier, string>;   // normal 普通 / large 大型 / sino 中外 / festival 节日SP / birthday 生日SP / graduate 毕业SP / debut 出道SP

```

`showVisibleIn(cityTier, def)` 三条同时成立才算可见：`city.types.includes(def.type)` && `city.levels.includes(def.tier)` && `def.slotCount <= city.maxSlots`。

**`scheduleWeek(cityTier, weekIndex, seed, festivalWeek = false)` 重写**（签名不变）：

1. 池子 = 所有 showId 分组中 `showVisibleIn(cityTier, defs[0])` 为真的。
2. 周末池 = `weekday !== 'midweek'` 且**非 festival 级别**；周中池 = `weekday === 'midweek'`。
3. `festival` 级别的演出**只有 `festivalWeek === true` 时才进候选**（不是"额外加一场"，而是参与本次抽取）。
4. 场次数一律从 `cityDef(cityTier)` 读：周末 `weekend` 场、周中 `midMin..midMax` 随机场（`midMax === midMin` 时就是固定值，不消耗随机数）。
5. **抽取按级别权重**，这是本次的关键语义（用户要求「普通占 80%」）：

```
pickWeighted(pool, count, rng):
  available = pool 里的 showId（每组一场）
  result = []
  while result.length < count && available 非空:
    tierWeights = 每个 tier 的权重 = 该 tier 所有演出的 weight（同 tier 一致，取任一场的值）
                   只统计「available 里还有演出的 tier」
    tier = 按 tierWeights 加权随机选一个
    show = available 里属于该 tier 的演出中度均匀随机选一个
    移除该 show，push
  return result
```

   实际效果：超一线周末 4 场，大约 3 场是普通级别，其余留给大场。**不要写死「普通 80%」这个数字**，权重从数据读。

6. 同一周内不得出现同一个 `showId`（`pickWeighted` 已保证）。
7. 返回的 `ShowOccurrence`：`id = ${weekIndex}:${showId}`（保持）、带 `tier`、`slotCount`、`slots`。

**`occurrenceVisible(run, occ)`** 保持现有实现，但要能处理 `visibleCond` 为空串的情况（现状 `parseCond` 已处理，别改坏）。

### 3.2 新增用例（缺一条就算没做完）

1. **每个城市的场次数 == cities 配置**：`scheduleWeek(3, ...)` 恒 1 场、`(2,...)` 恒 2 场、`(1,...)` 恒 4 场；超一线跑 30 周，周中场次数每次都落在 `[midMin, midMax]`。
2. **顺位上限真的生效**：三线跑 50 周，所有 `occ.slots.length <= 7`；二线 `<= 10`；一线 `<= 15`。
3. **类型白名单真的生效**：三线跑 50 周，`type` 只能是 `circuit|shoot`。
4. **级别白名单真的生效**：三线跑 50 周 `tier === 'normal'`；二线不出 `festival|birthday|graduate|debut|sino`。
5. **普通占大头**：超一线跑 100 周共约 400+ 场，`tier === 'normal'` 的占比落在 `0.5 ~ 0.92`。**这条要能挡住「改成均匀随机」**。
6. **同周不重复**：任意一周的 `showId` 集合无重复。
7. **festival 只在节日周出现**：非节日周跑 50 周，不得出现 `tier === 'festival'`；`festivalWeek=true` 时至少能抽出 1 场（当城市允许）。
8. **同 seed 同结果**：`scheduleWeek(1, 7, 'x')` 调两次 `toEqual`。
9. **城市越大池子越大**（core 侧）：一线每周出现的 `showId` 集合在 200 周内是二线的超集——用并集断言，不要逐周比较。
